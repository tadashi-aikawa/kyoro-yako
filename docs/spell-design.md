# スペルカードの設計(仕掛け型)

迅雷戦の試作で固めた方針を、全ボス・中ボスへ広げるための設計書。弾幕の実装はこの表を正とする。

## 共通の方針

- 1枚1仕掛け。弾の量で押さず、仕掛けが読める密度にとどめる
- 仕掛けを初見で理解できるよう、予告を必ず入れる
    - 予告の例: 予告線・魔法陣・一拍の溜め・点滅・色の変化
- 難易度差は、仕掛けを変えずに弾数・弾速・予告の長さで付ける。予告はEasyほど長くする
- 仕掛けは、迅雷戦で使ったものとできるだけ重ねない
    - 迅雷戦で使った仕掛け:
        - 画面外から戻って追いかける、寿命10秒のハート
        - 回転レーザー
        - 自機位置へ遅れて落ちる雷
        - 乱れ桜と突風
        - 螺旋の花吹雪
        - 横断のあとに向き直る列と中央での雷・花びらの発散
        - 全員へダメージを与えられる三身の同時射撃
- 通常攻撃は、今の弾幕を流用してよい(体力と制限時間だけ直す)

## 体力と制限時間

体力は「その面で想定するPower」で撃ち込み続けたときの撃破秒数から決める。通常攻撃は約14秒、スペルは約25秒を基準にする。

| 面 | 想定Power | 想定火力(ダメージ/秒) |
|---|---|---|
| 1 | 1.00 | 32.4 |
| 2 | 2.00 | 48.6 |
| 3 | 3.00 | 48.6 |
| 4 | 4.00 | 64.8 |
| 5 | 4.00 | 64.8 |

| 種類 | 撃破秒数 | 制限時間 |
|---|---|---|
| 通常攻撃 | 約14秒 | 40秒 |
| スペル | 約25秒 | 60秒 |
| 中ボスのスペル | 約18秒 | 45秒 |
| 耐久スペル | なし(時間切れで取得) | 各スペルの表に書く |

- 体力 = 撃破秒数 × 想定火力。この式をコードに1か所だけ置き、各フェーズは「種類」と面から計算する
- 迅雷戦の体力もこの式で出したものと一致させる(いまの数値と同じになる)

## フェーズの並び

前半は通常攻撃とスペルを交互に、最後の2〜3枚はスペルを連続で出す。

| ボス | 並び |
|---|---|
| スペル4枚 | 通常1 → S1 → 通常2 → S2 → 通常3 → S3 → S4 |
| スペル6枚 | 通常1 → S1 → 通常2 → S2 → 通常3 → S3 → 通常4 → S4 → S5 → S6 |
| スペル7枚 | 通常1 → S1 → 通常2 → S2 → 通常3 → S3 → 通常4 → S4 → S5 → S6 → S7 |

## 1面

### エトキチ(中ボス)

| スペル | 仕掛け | 抜け方 |
|---|---|---|
| エトワールの輪 | 重力でこぼれる星。エトキチの体の輪を模した、傾いた楕円軌道を星弾がゆっくり回る。輪の星が一定間隔で1つずつ光り、光った星が輪から外れて放物線を描いて落ちる | 光った星の落下点を読み、その間に立つ。1面の中ボスなので最も易しく |
| エトキチギャラクシーフラッシュ | 輪の次に使う2枚目。星光を手元へ収束させ、予告の方向へ紫と水色の太い光線を1.5秒放つ。発射時だけ疎らな星の輪も広がる。6秒ごとに位置を変えて撃ち直す | 溜め中に予告帯から横へ出て、光線と星の間で撃ち込む。照準は溜め開始時に固定 |

- 原作の参照: [エトキチの大冒険の技定義](https://github.com/tadashi-aikawa/etokichi-adventure/blob/main/src/game/characters.ts)と[ギャラクシーフラッシュの演出](https://github.com/tadashi-aikawa/etokichi-adventure/blob/main/src/rendering/pixi-effects.js)。
- 2枚とも通常の中ボス体力と制限時間を使う。補充とボーナスは各枚の終了時、回収待ちは2枚目の後に入る。

### ネオ(ボス。スペル4枚)

1面のボスなので、全ボスの中で最も易しくする。

| # | スペル | 仕掛け | 抜け方 |
|---|---|---|---|
| S1 | QWERTY流星群 | QWERTYの実配列を使い、英単語を毎回抽選する。単語に含むすべてのキーが光り、予告後にそれぞれの位置から落ちる。直前と同じ単語は選ばない。文字数はEasyが3〜4、Normalが6、Hardが8、Lunaticが9 | 単語と光るキーを見て、複数の段から降るキーの間へ入る |
| S2 | ノーマルモードから逃がさない | 短いコマンド予告の後、連射・左右移動・コピー・消去を通常弾で表す。複合コマンドも含む9パターン。詳細は[Vimコマンド弾幕](vim-command-pattern.md) | コマンドを見て弾の向きと繰り返しを読み、扇の間を抜ける |
| S3 | dotfilesの沼 | 沼の領域。画面に紫の円(沼)が2〜3か所広がる(予告で輪郭が点滅)。沼の中では弾が大きく減速して溜まり、自機も移動が遅くなる | 沼を避けて動く。沼に溜まった弾が沼から出る瞬間に注意 |
| S4 | リターン・トゥ・センダー | 半透明の予告文字はショットを通す。一斉落下後は、文字に当たったショットを斜め下へ反射する。各波でX座標と抜け道が変わる | 予告中や文字の隙間からネオを狙い、落ちる文字と反射弾を避ける |

- 通常攻撃は、遅い自機狙いの扇と固定方向の星の扇を半拍ずらして交互に撃つ。短い3連打と画面上端からの星格子を外す。
- QWERTY流星群では、配列の外側を退避場所として残す。
    - 理由: 1枚目はキーの落下を読む導入とする。固定位置への対策はVimとEnterで行う。

### クロディーヌ(ボス。スペル6枚)

| # | スペル | 仕掛け | 抜け方 |
|---|---|---|---|
| S1 | 削ぎ落とされた美 | 削られる壁。密な弾の壁が上から降りてくる。降りる途中で、壁の一部が薄く光ってから削ぎ落とされて消え、幾何学的な余白(道)ができる | 光った部分を見て、削られてできる道へ入る |
| S2 | タイポグラフィの雨 | 12文字・3書体の文字が雨のように降る。4秒ごとに小雨・豪雨・台風へ変化し、速さと密度、横風と回転が変わる | 天候の予告を見て密度と風向きに備え、文字の間を抜ける |
| S3 | グリッドシステム | 均等列・可変幅・可変行・千鳥配置を薄い弾で予告する。予告後に一斉に実体化し、格子を保ったまま下・右・上・左へ流れる | 予告された格子と方向を見て、移動する行や列の間を抜ける |
| S4 | 補色の対比 | 領域で性質が変わる弾。画面の左右で背景が補色(青と橙)に分かれ、境界はゆっくり左右に揺れる。弾は青の側では遅く、橙の側では速くなり、色も変わる | 自分のいる側と、弾が境界を越える瞬間の加減速を読む |
| S5 | 余白は語る | 動く安全地帯。画面全体に弾の地模様が敷かれ、中に「余白」の円(弾のない領域)が1つある。余白の円はゆっくり動き、大きさも変わる | 余白の円に入り、動きについていく |
| S6 | よろしければ、また | 耐久スペル60秒。S1〜S5を順に軽く再演する。残り10秒で旧弾を消し、1秒の専用カットインと構えを挟む。紅白の六弁の薔薇弾を回転させて連射し、半拍ずれた金色の自機狙い扇弾を重ねる。最後の4.5秒で弾速を上げ、時間切れまで撃ち続ける | 薔薇の花弁の間を抜け、自機狙いを引きつけて切り返す |

- 最後の10秒は、濃い葡萄色の背景と細い金の薔薇を背に専用ポーズで攻撃する。
    - 予告: 発射まで1秒の無弾時間を置く。既存の開始演出による105フレームの遅れは持ち込まない。
    - 軌道: 発射後は直進する。自機狙いは発射時の位置だけを狙う。
    - 終了: 60秒の時間切れで残弾を消し、取得と戦闘後会話へ進む。

## 4面

迅雷戦は `docs/spec.md` の迅雷戦の節を参照。Power 4.00を想定し、体力を通常907・スペル1620・中ボス1166へ合わせる。

- 中ボスは単身の「宵雷の扇」。角度をずらした針弾の扇を二連射する。
- ボスは「夜桜の舞」の次に「花影」を使う。単身で5秒撃ち、印を結ぶ溜めとゆっくりした分身で二身になる。残り20秒でもう一度溜めて三身になる。
    - 休止: 溜め開始時に残弾を消し、溜めと分身中は撃たない。
    - 射撃: 各人が通常攻撃と同じ高速針弾を同時発射し、全員が共有HPへの命中対象になる。

| エトキチギャラクシーフラッシュ | 1面より太い固定照準の光線を5秒周期で放ち、1.25秒周期の星の輪を重ねる。光線の予告・発射中は本体が停止する | 予告帯から横へ出て星の輪を抜け、移動中に撃ち込む |

- スターリングと五芒星の突撃技を弾幕へ翻案する。
