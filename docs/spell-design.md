# スペルカードの設計(仕掛け型)

迅雷戦の試作で固めた方針を、全ボス・中ボスへ広げるための設計書。弾幕の実装はこの表を正とする。

## 共通の方針

- 1枚1仕掛け。弾の量で押さず、仕掛けが読める密度にとどめる
- 仕掛けを初見で理解できるよう、予告を必ず入れる
    - 予告の例: 予告線・魔法陣・一拍の溜め・点滅・色の変化
- 難易度差は、仕掛けを変えずに弾数・弾速・予告の長さで付ける。予告はEasyほど長くする
- 仕掛けは、迅雷戦で使ったものとできるだけ重ねない
    - 迅雷戦で使った仕掛け:
        - 壁で跳ね返る
        - 回転レーザー
        - 自機位置へ遅れて落ちる雷
        - 乱れ桜と突風
        - 螺旋の花吹雪
        - 横断のあとに向き直る列と中央での雷・花びらの発散
        - 全員へダメージを与えられる三身の同時射撃
- 通常攻撃は、今の弾幕を流用してよい(体力と制限時間だけ直す)

## 体力と制限時間

体力は「その面で想定するPower」で撃ち込み続けたときの撃破秒数から決める。通常攻撃は約14秒、スペルは約25秒を基準にする。

| 面 | 想定Power | 想定火力(ダメージ/秒) |
|---|---|---|
| 1 | 1.00 | 32.4 |
| 2 | 2.00 | 48.6 |
| 3 | 3.00 | 48.6 |
| 4 | 4.00 | 64.8 |
| 5 | 4.00 | 64.8 |

| 種類 | 撃破秒数 | 制限時間 |
|---|---|---|
| 通常攻撃 | 約14秒 | 40秒 |
| スペル | 約25秒 | 60秒 |
| 中ボスのスペル | 約18秒 | 45秒 |
| 耐久スペル | なし(時間切れで取得) | 各スペルの表に書く |

- 体力 = 撃破秒数 × 想定火力。この式をコードに1か所だけ置き、各フェーズは「種類」と面から計算する
- 迅雷戦の体力もこの式で出したものと一致させる(いまの数値と同じになる)

## フェーズの並び

前半は通常攻撃とスペルを交互に、最後の2〜3枚はスペルを連続で出す。

| ボス | 並び |
|---|---|
| スペル4枚 | 通常1 → S1 → 通常2 → S2 → 通常3 → S3 → S4 |
| スペル6枚 | 通常1 → S1 → 通常2 → S2 → 通常3 → S3 → 通常4 → S4 → S5 → S6 |
| スペル8枚 | 通常1 → S1 → 通常2 → S2 → 通常3 → S3 → 通常4 → S4 → 通常5 → S5 → S6 → S7 → S8 |

## 1面

### エトキチ(中ボス)

| スペル | 仕掛け | 抜け方 |
|---|---|---|
| エトワールの輪 | 重力でこぼれる星。エトキチの体の輪を模した、傾いた楕円軌道を星弾がゆっくり回る。輪の星が一定間隔で1つずつ光り、光った星が輪から外れて放物線を描いて落ちる | 光った星の落下点を読み、その間に立つ。1面の中ボスなので最も易しく |

### ネオ(ボス。スペル4枚)

1面のボスなので、全ボスの中で最も易しくする。

| # | スペル | 仕掛け | 抜け方 |
|---|---|---|---|
| S1 | 全画面キーバインド | 押されたキーだけ落ちる。画面上部にキーボード配列(3段)の形でキーキャップ弾が並ぶ。ネオが「押した」キーが光り、一拍おいてそのキーだけが真下へ落ちる | 光ったキーの真下から外れる |
| S2 | このキーボード、いいでしょ！ | 自機を囲む円。自機の周りにキーキャップ弾が円く並ぶ(予告の薄い円)。円は一拍おいてゆっくり縮み、途中で止まってから外へ弾ける。円には1か所切れ目がある | 縮む前に切れ目から外へ出るか、弾ける瞬間に切れ目へ入る |
| S3 | dotfilesの沼 | 沼の領域。画面に紫の円(沼)が2〜3か所広がる(予告で輪郭が点滅)。沼の中では弾が大きく減速して溜まり、自機も移動が遅くなる | 沼を避けて動く。沼に溜まった弾が沼から出る瞬間に注意 |
| S4 | Enterで一斉送信 | 横一列に止まる文字列。小弾が左から右へタイピングのように1発ずつ置かれて横一列に並ぶ。行末で「↵」が光ると、その行が一斉に下へ落ちる。行は上から順に積まれる | 行が落ちる前に、行と行の間の高さへ移る |

## 4面

迅雷戦は `docs/spec.md` の迅雷戦の節を参照。Power 4.00を想定し、体力を通常907・スペル1620・中ボス1166へ合わせる。

- 中ボスは単身の「宵雷の扇」。角度をずらした針弾の扇を二連射する。
- ボスは「夜桜の舞」の次に「花影」を使う。単身で5秒撃ち、印を結ぶ溜めとゆっくりした分身で二身になる。残り30秒でもう一度溜めて三身になる。
    - 休止: 溜め開始時に残弾を消し、溜めと分身中は撃たない。
    - 射撃: 各人が通常攻撃と同じ高速針弾を同時発射し、全員が共有HPへの命中対象になる。

## 5面

### ネオ(中ボス。再登場)

- 「最後」と言ってからが長いは、今の仕掛け(時間切れのたびに延長し、弾幕が1段階ずつ変わる)のまま使う
- 延長の各段で、1面のネオのスペルS1〜S3の仕掛けを1つずつ使う
- 体力だけ共通の式に合わせる
