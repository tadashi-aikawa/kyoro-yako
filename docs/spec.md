# 梟楼夜航 — きょうろうやこう 仕様

owleryのAIメンバーとエトキチが登場する、縦スクロールの弾幕シューティング。みみこを操作してブラウザで遊ぶ。

## 技術

- Vite + TypeScript(strict)+ Canvas 2D。フレームワーク・ゲームエンジンは使わない
- pnpm。Biome(recommended。`noNonNullAssertion` / `noExplicitAny` はoff)。テストはVitest
- `pnpm check` で typecheck + lint + test + build をまとめて通す
- ファイル名はkebab-case。モジュールは責務ごとに小さく分ける
- 論理座標は640x480固定。表示はウィンドウに収まる最大の実数倍で中央に置く。canvasの実ピクセルは表示倍率とdevicePixelRatioを掛けたサイズにし、`setTransform` で論理座標に合わせる。画像補間は高品質にする
- 固定タイムステップ60fps。描画はrequestAnimationFrame、更新は累積時間で1/60秒ずつ回す(1フレームあたり最大4ステップまで)
- 弾・敵・アイテムはオブジェクトプールで管理し、画面内の弾2000発でも60fpsを保つ
- 弾のスプライトは種類×色ごとにオフスクリーンcanvasへ実ピクセル倍率で描き、表示倍率変更時に再生成する。glowもキャッシュへ焼き込む

## 画面レイアウト

- 左: プレイフィールド 384x448。左上 (32,16)
- タイトル: 背景はキービジュアル `public/assets/title/key-visual.webp`(4:3)。梟楼の各階の窓辺に5面のボスがいて、みみこが塔の前を飛ぶ。左の暗い余白に題字とメニューだけを重ね、説明的な文言は置かない。
- 右: みみこの冒険ノート。5面の道のり、今回のスコアと最高記録、現在の自機を含めた残り回数、ボム数、ショット強度を表示する。
- 右パネルは夜色のノート。綴じ環・罫線・しおりを添える。
- 残り回数は小さいみみこを並べる。8回以上は7個と追加数で表示する。
- ボムは8枠の二重の輪を所持数だけ灯す。
- ショット強度は5本の羽根と数値で表す。
    - 端数: 次の羽根を途中まで灯す。最大値は「MAX」と表示する。
    - 最高形態: 5本すべてが金色に光り輝き、数値欄は「最高形態」と表示する。自機の周囲の光球とショットも金色になる。
- 下部はみみこの顔と集めた記録の頁を置く。
- 背景: 各階の床と建築を多層で縦スクロールする。手前の柱・書架・額縁・桜・天文台の構造も画面外まで流し、奥の層は遅く動かす。必殺技中は暗い背景とボスの色の魔法陣を重ねる。

## 操作

| キー | 動作 |
|---|---|
| 矢印キー | 移動(斜め移動は正規化) |
| Shift | 低速移動。自機の当たり判定の点と、周囲の薄い円を表示する。ショットが集中型に変わる |
| Z | ショット(押しっぱなしで連射)/ メニュー決定 / 会話送り |
| X | ボム / メニュー戻る |
| Esc | ポーズ(再開 / タイトルへ戻る / やり直し) |
| Ctrl | 押している間、会話を早送り |

## 素材

- `public/assets/members/<slug>-face.webp`(540x540、透過)と `<slug>-stand.webp`(多くは縦長。mimikoとetokichiは正方形)
- `public/assets/sprites/<slug>.webp` はフィールド用の透過SDスプライト。未配置・読み込み失敗時はstand画像へ縮退する
- 中ボス・ボスに出る7体は `<slug>-idle.webp` / `<slug>-left.webp` / `<slug>-right.webp` / `<slug>-cast.webp` も持つ(`src/boss-motion.ts` の `MOTION_BOSSES`)
    - 構え(`cast`)は実際の発射から24フレーム出す。通常攻撃と技の途中の発射で共通。
        - 開始時: スペル・中ボスの技は、カットインが明ける105フレーム目から40フレーム構える。
        - 予告: 遅延弾・輪・レーザーは予告終了後の発射時に反応する。
        - 連射: 構えを始めてから60フレーム未満の追加発射は、構え時間を延長しない。
    - 優先順: 技の専用ポーズ > 構え > 移動 > 待機
    - 待機中は元絵と `idle` を22フレームごとに交互に出す。花影の分身も待機のコマをずらし、射撃中の個体は構える。
    - 元絵の白が半透明のボスは、待機で元絵の代わりに描き直した `<slug>-base.webp` を出す(`REDRAWN_BASES`)。元絵は自機・会話などほかの用途にそのまま使う
    - 横移動の速度を平滑化し、0.3px/フレームを超えたら `left` / `right` へ切り替え、0.18px/フレームを下回ったら待機へ戻す
    - 24px/フレームを超える飛びとフェーズの切り替えは瞬間移動として待機から数え直す
    - 動きの絵が読み込めていなければ元絵へ縮退する
- slug: neo / minerva / mimiko / obsidia / jinrai / claudine / chappy / etokichi
- 用途
    - 自機・ボス・中ボスのフィールド上の姿: sprite画像を描く(自機は高さ約40px、ボスは高さ約64px)。緩やかな上下動と左右移動時の小さな傾きを付ける。ボスの背後に回転する魔法陣を描く
    - 会話: stand画像を左右に大きく出す(左=自機、右=ボス)。話していない側は暗くする
    - スペルカットイン・タイトル・エンディング: stand画像。カットインの高さは論理座標で360px以上
    - 自機選択画面・サイドパネル: face画像。現在は自機1人なので選択画面を飛ばす
    - エトキチの正方形stand画像は、会話とカットインで横幅を広く取り、ほかの人物と見た目の大きさを揃える
- 雑魚敵はowlery(フクロウ小屋)にちなんだ**小さなフクロウ**。画像を使わずcanvasで描く(丸い胴・大きな目・耳羽。色違いで種類を分ける)。羽ばたきは簡単な2コマでよい
- 効果音はWebAudioでその場で合成する(ショット・被弾・グレイズ・敵撃破・ボム・スペルカード宣言・スペル取得・アイテム取得・エクステンド)
- 音量はタイトルの設定で0〜100%(既定50%)。localStorageへ保存する(アクセス失敗時は既定値で動く)

### BGM

- 曲ファイルと場面の対応は `docs/bgm.md` に従う。MP3は `public/assets/bgm/` に配置する
- メニューはtitle、道中と中ボスは各ステージ曲を流す。ボス戦前会話から撃破後会話・餞別・退場を経てクリアに入るまでは各ボス曲を流す。ステージクリアでは停止し、エンディングとスタッフロールはendingを流す
- 5面の道中終了時は、白フェード開始から約1秒かけてstage-dawnを通常の35%へ滑らかに下げる。動画中と動画後の白フェード・白保持中も、同じ道中曲を止めずに流す
    - lastbossの動画音声は使わない
    - ミネルヴァの登場開始と白明けの開始で、boss-minervaへ約1秒でクロスフェードする。道中曲は下げた音量からフェードアウトする
    - 演出用の音量倍率は、ポーズ・ゲームオーバーの倍率と独立して指定する
        - ポーズ・ゲームオーバーでも現在の演出倍率を保ち、その上からポーズの減衰を掛ける
    - 白保持の開始でboss-minervaを先読み・デコードし、白明けの開始と同時にクロスフェードを始める
    - 動画が未配置・再生失敗・スキップの場合と、`?movie=lastboss`・`?stage=5&from=boss`でも同じ順に切り替える
- 曲の切り替えは約1秒のクロスフェードでつなぐ。デコード後の波形から、先頭と末尾に0.3秒以上続く-45dBFS未満の無音を曲ごとに検出して除く。0.2秒以下の短い音が無音を分断する場合は一続きの無音として扱う。ループは有音区間の末尾約2秒と頭をクロスフェードでつなぐ。ポーズ・ゲームオーバー中は音量を下げる
- 最初のキー入力後に再生を開始する。必要になった曲だけ取得・デコードして使い回す。未配置の曲は無音で進める
- Optionで効果音とBGMの音量を別々に設定する。BGMの既定は60%。どちらもlocalStorageへ保存し、失敗時は既定値で動く
- 動画ごとの音の有無は `src/movies.ts` の `MOVIE_SETTINGS` に従う。openingは音あり、lastboss・jinrai-gift・minerva-finale・endingは無音で再生する
    - 音ありの動画ではBGMを約1秒かけて無音へクロスフェードする。動画の音量はOptionのBGM音量に追従する
    - 動画の終了・スキップ・再生失敗後は次の場面の曲へ切り替える
        - 例外: lastbossは白保持が終わり、登場が始まるまで下げたstage-dawnを保つ
    - 無音動画ではBGMを流す。openingを無音設定にした場合はstage-gate、lastbossは音量を下げたstage-dawn、jinrai-giftはboss-jinrai、minerva-finaleはboss-minerva、endingはendingを使う
    - 音あり動画が `NotAllowedError` で再生拒否された場合は、無音にして1回だけ再試行する。openingの再試行中はstage-gateを流す
    - `?bgm=0` ではBGMと動画の音をともに無効にする

## ゲームの流れ

タイトル → 難易度選択(Easy / Normal / Hard / Lunatic) → opening → ステージ1 → 2 → 3 → 4面迅雷戦 → 白 → jinrai-gift → 対峙 → 撃破後会話 → 餞別 → 退場 → 4面クリア → 5面道中 → lastboss → ミネルヴァ戦 → 白 → minerva-finale → 対峙 → 撃破後会話 → 退場 → 5面クリア → ending → エンディング → スタッフロール → タイトル

- タイトルのメニュー: はじめる / 練習(クリア済みのステージを選んで遊ぶ。未クリアなら1のみ)/ 音の設定(音量)/ 遊び方 / 冒険ノート(集めた記録を読む)
- ハイスコアは難易度ごとにlocalStorageへ保存する
- ステージの間に「Stage Clear」と、クリアボーナス(ステージ番号×100万+残機・ボム・Power・Point・Grazeによる加算)の画面を挟む
    - 配布前の状態でクリアボーナスを計算し、クリア時に加算する
        - 除外: 1〜3面の退場報酬、4面の餞別で増えた残機・ボム・Powerはクリアボーナスに含めない
- 本ボスの最終フェーズ終了後は全5面・練習で共通の流れを使う
    - 撃破直後: 敵弾・自機弾・残った敵とアイテムを消す。撃破の点・小Pは出さない。ボスは撃破時の位置に待機ポーズで残し、8フレームの閃光を出す
        - 被弾: 撃破と同時の被弾猶予は取り消す
    - 白へ: 閃光後に90フレームで白へ溶かす
        - BGM: ボス曲を約1秒で演出倍率35%へ下げて継続する
        - 移動: 閃光と白フェードの計98フレームでボスを撃破時の位置から定位置へ滑らかに寄せる
        - 更新: この98フレーム中も背景は毎フレーム1.8pxスクロールし、無敵時間を減らす
        - 入力: 閃光・白へのフェード・白保持中のEsc・Xは無視する
    - 1〜3面: 動画を挟まず、白を60フレーム保持する
    - 4・5面: 下記の無音動画を白から再生し、終了・スキップ・失敗後は150フレームで白へ溶かして60フレーム保持する
    - 対峙: 120フレームで白を明ける
        - ボス: 最初から定位置に立ち、降下しない
        - BGM: 演出倍率を約1秒で1へ戻す
    - 会話: 既存の撃破後会話を使う
        - 入力: 白明け中は会話送りを受け付けない
    - 退場: ボスが光の粒子を散らし、60フレームで上へ消える
        - 1〜3面: 退場開始と同時に残機1個・ボム1個・大型パワー1個を投げて自動回収する
            - 投擲: ボスの定位置から扇状に3個を放つ。4面の餞別と同じ50フレームの放物線で動き、その間は吸引・取得しない
            - 吸引: 投擲後は4面の餞別と同じ毎フレーム4px以下で自機へ寄せる。時間制限や強制回収は設けない
            - 進行: 光の退場演出60フレームと並行する。退場演出が終わり、全品が取得または画面外への消失でなくなるまで余韻の開始を待つ
            - 抽選: Power5かつ最高形態でない場合だけ、大型パワーを5%で光の羽根に置き換える
            - 非当選・対象外: 大型パワーのまま
        - 4面: 会話後に既存の餞別を投げる。全品の回収・消失後に退場する
        - 5面: アイテムを出さず退場する
    - クリア: 全5面で退場60フレーム・光の粒子の消失・アイテムの回収または消失をすべて待つ。その後、背景だけが流れる余韻を90フレーム挟んでクリア画面へ進む
        - 操作: 余韻中も自機の移動は許可し、射撃とボムは止める。ポーズ中は余韻の時計も止める
    - 操作: 撃破演出・対峙・餞別・退場中は移動のみ許可し、射撃・ボム・被弾を止める
    - 中ボス: 従来の撃破アイテムと180フレームの回収時間を保つ
- ムービーは `public/assets/movies/` の同名MP4を使う。公開用baseパスに追従する
    - openingは通常プレイの難易度決定後だけに流す。練習とステージ・ボス直行では省略する
    - lastbossは5面の道中終了後、ミネルヴァ戦前会話の直前に流す
        - 道中終了後に画面全体を90フレームかけて徐々に白へフェードする。道中曲はこの白フェードの開始から約1秒で通常の35%まで下がる
        - 動画の最初の1.5秒で白が徐々に明け、動画が見えてくる。60fps換算で90フレームとし、動画は白の下で最初から再生する
        - 動画終了後は最後の映像を止め、150フレームで白へ溶かす。白いっぱいの画面を60フレーム保ち、120フレームで白が明けながらミネルヴァの登場へ進む
        - Z・Xでスキップした場合も、その時点の映像を止めて同じ白フェード・白保持・登場へ進む
        - 未配置・読み込み失敗時も白フェード・白保持を経て登場へ進む。映像が無ければ白を保ったまま同じ時計を進める
        - 白保持中のZ・X・Escは無視する。openingとendingの動画にはこのフェードを付けない
    - endingは5面クリア画面のZ後に再生する
        - 原本3本から29.5秒の動画を編集する。1→2は1.5秒の白フェード、2→3は3本目の冒頭1秒を切り、0.25秒のディゾルブでつなぐ。最後の朝空を2.25秒延長して暗転する
        - 原本はGit管理外の `_Unversioned/assets/movies/` に保存し、`scripts/build-ending.sh` で再編集する
    - jinrai-giftは4面本ボス撃破後の白フェード直後に流す。minerva-finaleは5面で同じ流れを使う
        - 動画の最初の1.5秒で白が明ける。60fps換算で90フレームとし、動画は白の下で最初から再生する
        - 終了・Z・Xでのスキップ後は、その時点の映像を止めて150フレームで白へ溶かす。白を60フレーム保持し、120フレームの白明けで対峙へ戻る
        - 未配置・再生失敗でも同じ白フェード・白保持を経る。映像が無ければ白を保ったまま進む
        - 動画・白演出中はboss-jinraiまたはboss-minervaを演出倍率35%で継続し、対峙開始から通常音量へ戻す
    - 動画は640×480の画面全体を使い、中央640×360に描画する。上下60pxは黒。冒険ノートは隠す
    - ZかXでスキップする。エンディング動画は残り全部を飛ばす。Escは無視する
    - 未配置・読み込み失敗・再生拒否時は次の場面へ進む。読み込みと再生開始の待機上限は1秒。再生がバッファ待ちで止まった場合も1秒で進む
    - タイトルでopeningを先読みする。4面開始でjinrai-gift、5面開始でlastboss・minerva-finale・endingを先読みする。失敗した素材を繰り返し取得しない
- 4面の撃破後会話が終わると、迅雷が定位置から餞別を扇状に投げる
    - 内容: 残機3個、ボム3個、光の羽根1個
    - 投擲: 最初の50フレームは放物線で落とし、その後は自動回収する
        - 吸引: 通常アイテムの自動回収に近い速さでゆっくり自機へ寄せる。餞別の吸引速度は毎フレーム4pxを上限にする
    - 操作: 自機移動のみ。射撃・ボムを止め、ポーズ中は投擲と回収を止める
    - 演出: 餞別中も背景をスクロールし、パーティクルを更新する
    - 終了: 未回収の餞別が取得または画面外への消失ですべてなくなったら、60フレームの退場と光の粒子の消失を待つ。さらに90フレームの余韻を経てステージクリアへ進む
        - 時間制限: 設けない。強制回収もしない
        - 消失: フィールドの上下左右から20pxを超えて出たアイテムは、取得扱いにせず消す
    - 加算: 残機とボムは既存の取得処理に従う。ボムは上限まで加算する
- ステージ開始時は上下60pxの暗幕を45フレームで開く。暗幕中はstageFrameと敵waveを止め、自機移動だけを許可する
    - 題字はSTAGE番号・日本語題・英題を3段に表示する。各段を30フレーム遅れでフェードインする
    - 150フレーム後から30フレームかけて消す。ステージ直行でも表示する
- エンディングの6行は180フレーム間隔で、各60フレームかけてフェードインする
    - 夜色から朝色へ600フレームかけて移り、星も薄くなる
    - 朝への進行が0.5〜0.7の間で文字色を白から濃い色へ、影を4から0へ補間する
    - 見出しと操作案内は表示しない。全文表示・早送りを設けず、最後の行の表示後に4秒取り、自動でスタッフロールへ進む
    - スタッフロールの12枚構成・担当表・時間は後述の「会話」に従う

## 自機

| 自機 | 通常ショット | 低速ショット | ボム |
|---|---|---|---|
| みみこ | 追尾するフクロウの羽。威力は低め | 追尾を弱めて前方へ束ねる | 書いて残す七重の頁: 自機を中心に広がる7重の輪。敵弾を消して敵にダメージを与える |

- 自機定義は配列で管理する。2人以上になれば自機選択画面を表示し、1人の間は難易度選択から直接1面へ進む
- 当たり判定半径 2.5px、グレイズ判定半径 18px。低速時の移動速度は通常時の約45%
- Powerは0.00〜5.00。小Pで+0.05、大Pで+1.00増える。
    - 光球: 整数部分と同じ数が自機の周囲を回る。残機とは無関係。
    - 主攻撃: Power0〜4の発射数・威力・追尾を維持する。Power5でも4発を5フレームごとに撃つ。
    - Power5: 主攻撃に加え、左右それぞれ前方から15度・30度の2方向へ10フレームごとに撃つ。補助弾は追尾せず、威力0.65で主攻撃の1発1.35より弱い。
    - Power5の低速: 補助弾4発も正面へ集中させる。低速を解除すると斜め前方へ戻る。
        - 理論火力: 全弾命中なら毎秒80.4ダメージ。Power4の64.8より約24%増える。
- 最高形態: Power5で専用のレアアイテム「光の羽根」を取ると有効になる。Powerの数値は5のまま。
    - 例外: 4面クリア時の迅雷の餞別は、Power5未満でもPowerを5にして最高形態にする。
    - ショット: 中央5本を5フレームごと、左右それぞれ20度・40度の2方向へ2発ずつの束を10フレームごとに撃つ。1発の威力は通常のPower5と同じ。
        - 束: 同じ方向の2発は進行方向に垂直な6px間隔で並び、平行に進む。時間が経っても分散しない。
        - 追尾: 中央5本は追尾あり。左右8発は追尾なし。
        - 理論火力: 全弾命中なら毎秒112.2ダメージ。通常のPower5より約40%増える。
    - 低速: 左右8発も正面へ集中させる。束同士と中央の弾は重ならない位置に並び、束と束の間は束の中より広く空ける。解除すると斜め前方へ戻る。
    - 継続: ステージ移動・ポーズの「やり直し」・ボムでは解除しない。被弾が確定すると解除する。喰らいボム成功時は保つ。
    - 再取得: 通常のPを拾い直してPower5へ戻すだけでは復活しない。再び光の羽根が必要。
    - 新しいプレイとコンティニューでは解除する。
- 残機は初期2、画面には自機を含む3回と表示する。
- ボムは初期3個、所持上限8個。
    - 被弾時: 3個未満なら3個へ回復する。3個以上なら所持数を保つ。
- 被弾するとPowerが最大1.00減る。
    - 回収品: 失った量に相当する小Pをフィールドの広い範囲へ分散する。1.00なら20個、小Pは0.05単位で切り捨てる。
    - 回収: 上部への移動では一括回収しない。近づいた小Pだけ吸い寄せる。
    - 猶予: 被弾後の約8フレームは**喰らいボム**を使える。この間にXでボムを撃つと被弾を取り消す。
- 被弾後・ボム中は無敵(被弾後は約3秒点滅)
- エクステンド: スコア 1000万・2000万・4000万・6000万で残機+1
- 残機が尽きたらゲームオーバー。コンティニュー(スコアを0にして同ステージの最初から。回数無制限)するかタイトルへ戻るかを選ぶ

## アイテム

- 小Pは赤い羽根、大Pは一回り大きい赤い羽根で表す。
- 大Pは小Pの1.6倍の大きさで描く。
- 得点は青いしおり、ボムは緑の二重の輪、1UPはピンクの輪で囲ったみみこで表す。
- ボムの二重の輪は、薄い緑の膜とオーラで囲む。
- 光の羽根は、大Pと同じ48pxの金色の羽根の束で表す。正立と暗い縁を保ち、輪郭の外に小さなきらめきを付ける。
    - 出現条件: Power5かつ最高形態でないときだけ抽選する。
    - 出現率: 雑魚撃破ごとに0.3%。ボスの途中フェーズ終了時と中ボスは2%、4・5面の本ボスの途中フェーズは4%。1〜3面の本ボス退場時は大型パワーを5%で置き換える。
    - 抽選: 既存のライフとボムの出現率を保つ。雑魚は抽選値0.997以上の点アイテム枠、フェーズ終了時は0.32以上0.34未満の追加なし枠を置き換える。4・5面の本ボスは後者の境界を2倍にする。
    - 被弾後: 落下中の光の羽根をPower5未満で拾った場合は、大PとしてPowerを1.00回復する。最高形態にはならない。
    - 例外: 迅雷の餞別の羽根だけは、Power5未満でもPowerを5にして最高形態にする。通常のドロップ抽選は変えない。
    - 重複: 最高形態中に拾った場合は点アイテムの最大値を得点へ加える。
- HUDとドロップは共通の形を使う。
    - 識別: 羽根としおりは正立・暗い縁とし、敵弾の発光・白縁と分ける。
- 自機が上端ライン(フィールド座標 y < 112。上から1/4)より上にいる間は、画面中のアイテムを自動回収する
    - 例外: ボスの補充品と被弾時の小Pは手で拾う。
- 低速移動中はアイテムの吸い寄せ範囲が広がる
- 点アイテムの価値は取得した高さで変わる(上端ラインより上で最大値)。最大値は「Point」(初期1万)で、グレイズ数に応じて増える
- ボスの途中フェーズ終了時・中ボス撃破時は画面の弾を点アイテムに変えて自動回収する
    - 例外: 本ボスの最終フェーズ終了時は点アイテムへ変換せず消す
- ボスの各フェーズ終了時に小Pを散布する。
    - 1〜3面の本ボスと全中ボス: 小P10個。全部拾うとPowerが0.50増える。追加品はボム1個が30%、ライフ1個が2%、追加なしが68%。
    - 4・5面の本ボス: 小P20個。全部拾うとPowerが1.00増える。追加品はボム1個が60%、ライフ1個が4%、追加なしが36%。
    - 抽選: ボムとライフは同時に出ない。
    - 条件: 撃破でも時間切れでも支給する。本ボスの最終フェーズと中ボスの時間延長では支給しない。
    - 配置: ランダムに離れた位置へ散らす。上部へ移動しても一括回収せず、近づいて拾う。
    - 戦闘終了後: 中ボスの最後に3秒の回収時間を設け、その後に会話や道中へ進む。本ボスは白演出・対峙・会話・退場へ進む。
    - 理由: 会話中に停止する前に手動で回収できるようにするため。

## ステージ構成

各ステージは道中(雑魚フクロウの編隊)→ 中ボス → 道中後半 → 会話 → ボス → 会話(撃破後)で構成する。

- ボス前会話までの道中と中ボス戦は約90〜110秒。5面は中ボス戦の所要時間に合わせて道中後半を短縮する。
    - 下限: 道中時計2900フレームまでは進め、中ボス戦が長引いてもミネルヴァ戦へ到達できる。
    - 5面: エトキチの追加2技ぶんの標準時間2370フレームを足す。
        - 目安: 中ボス戦が約91秒以内なら道中と戦闘・回収の合計は約143秒。会話の時間は含めない。
        - 条件: 中ボスを全て時間切れにすると約186秒まで延びる。
    - 雑魚: 上半分で留まるか曲がって横または上へ退場する。射撃は入場30フレーム後かつ自機から150px以上離れている時だけ。

- 道中の編隊は弧を描く列、引き返す列、花弾を落とす横断群、自機狙い3way、単発狙い弾の掃射列、中央の全方位隊に、左右の挟み込み・蛇行・旋回・V字隊列を加えた10種。面と前後半で順序を変える。練習時にも同じ順序を再現する。

通常攻撃の弾幕の意図:

- ネオ「一打ずつ」: 遅い自機狙いの扇と、固定の下向きの星の扇を交互に放つ。短い連打と画面上端の格子を使わず、1面の回避練習にする。
- オブシディア「整列」: 自機が通れる間隔の横一列の文字弾を、左右へ斜めに進める。2色を交互に使い、列を重ねて密度を出す。通常2は2列を短い間隔で続ける。
- クロディーヌ「対称」: 左右対称の素直な花弁アークと全方位リングを2色交互に連ねる。特定の安全地帯を追わせず、均等な弾間を抜ける。
- 迅雷「速度」: ボス位置から他ボスより速い針弾を全方位へ連射する。自機狙いの扇は1周期に1回だけ混ぜる。短いアタックの強い専用SEを発射に同期する。
- ミネルヴァ「星の重奏」: 現在の自機位置を狙う星弾の扇と、全方位の星弾リングを交互に放つ。停止や再照準を使わず、最も密度の高い直進弾幕にする。

全難易度で斉射の弾間を保ち、発射周期で密度を増やす。

Normalの2〜5面の通常攻撃は道中の1.1倍以上、弾数・通過量とも旧版の通常攻撃以下とする。道中との比較は迅雷だけ通過量、他は画面内平均弾数を使う。1面の通常攻撃は道中より疎らにする。

オブシディアの列は、画面上外のy=-8から発射する。ネオの通常攻撃はボスの位置から発射する。

スペルカードの弾幕の意図(実装はこの意図を満たせば自由):

- エトワールの輪: 傾いた楕円軌道を星弾が回る。光った星が順に輪からこぼれ、重力で落ちる
- エトキチギャラクシーフラッシュ: 輪の次の2枚目。原作と同じ星光の収束から、紫と水色の光線を放つ。溜め開始時に照準を固定し、予告帯を見て横へ退ける。光線と一緒に疎らな星の輪を放つ
- QWERTY流星群: 英単語を毎回抽選し、含まれるキーをQWERTY配列の各位置から落とす。Easyは3〜4文字、Normalは6文字、Hardは8文字、Lunaticは9文字。直前と同じ単語は続けない
- ノーマルモードから逃がさない: Vimコマンドを予告して通常弾を発射する。
    - 攻撃: 下向きの連射、左右への2段移動、弾幕のコピー、先行弾の消去を組み合わせる。
    - 複合: `3j2hyyp`など、複数の操作を続けるコマンドも使う。
    - 詳細: [Vimコマンド弾幕](vim-command-pattern.md)。
- dotfilesの沼: 紫の沼に入った弾と自機が減速する。輪郭を点滅させて領域を予告する
- リターン・トゥ・センダー: 左から1発ずつ並んだ文字弾が、↵の点灯後に横一列で落ちる。各波でX座標と広い抜け道をずらす。穴の位置を示す予告線は出さない
    - 予告中: 半透明の文字は自機ショットを通す。
    - 反射: 発射済みの文字に当たった自機ショットはネオへ通らず、斜め下の反射弾になる。
    - 連射: 同じ文字から返す間隔はEasyから順に30・22・16・12フレーム。
    - 抜け道: 文字が落下している間のネオの移動先へ寄せる。
- 書棚の呼吸: 左右それぞれ6段から3段ずつ交互に背表紙が光り、幅約40%まで本棚が突き出てから引っ込む。先端から小弾が3発こぼれる
- 断捨離: 全方位のリングで光る一部の弾が点滅後に消え、通り道が開く
- グラフビューの天網: ノートの丸とリンクの線が画面広域へ枝分かれして増える。
  - 成長: 12秒周期。Easyから順に最大20・26・32・38ノートを26・20・16・14フレーム間隔で加える。8個目から4個おきに生成時の自機位置へ置き、予告後は追尾しない。既存ノートに重なる場所では追加せず、元の予告を延長しない。
  - 予告: 96・80・66・54フレーム。中抜きの丸と金色の点線から、塗られた丸と幅3pxの実線へ変わる。描画と同じ丸・連続線分で判定する。
  - 接続: 既存ノートのうち近い親へ結ぶ。交差や閉路を作らず、自機ショットは通す。壁から32px未満のノートは独立させ、壁同士をリンクで結ばない。
    - 隙間: 新しいノートとの隙間が6px以下になる古いノートや枝は、先に無害化してほどく。新しい線も、接続先以外のノートに対して6px超の隙間を残す。
  - 更新: 11秒で網を無害化して1秒かけて消す。次の網と重ねない。線とノートは個別に1回だけグレイズできる。
  - ボム: ノート・線・成長の時計を消し、ボム明けは種から育ち直す。ポーズでは止まった状態を保つ。
  - 終了: ノートだけを1個につき得点アイテム1個へ変え、専用状態を消す。
- #タグ・グラビティ: 3色の魔法陣が出現し、同じ色の弾が対応する陣へ曲がる
- インボックス・ゼロ: 発散地点へ移動し、専用の集中ポーズで胸元へ紫の光を集め、周囲へ全方位の弾幕を3連続で放つ。

5面中ボスは強化エトキチの3技。各技HP1166、制限時間45秒、Power 4.00で約18秒。3技の後に回収と会話へ進む。詳細は `docs/spell-design.md` の5面を参照。

- 体力は通常攻撃約14秒・スペル約25秒で倒せる量に調整している。ミネルヴァの最終技は被ダメージ2/3で約90秒分とし、再演前の召喚時間を別に加える。

### スペルカードの共通仕様

- 宣言時にボスのカットイン(stand画像が画面を斜めに横切る)と、右上にスペル名の帯を出す
- スペルボーナス(開始時の値から時間とともに減る)を表示し、被弾もボムもなしで倒すと「技の記録ボーナス！」と加算する
- 通常攻撃は40秒、本ボスのスペルは60秒、中ボスは45秒。ミネルヴァの最終技と迅雷一閃は時間制限∞で撃破必須とする。時間制限のある技は、耐久スペル以外の時間切れを取得失敗扱いで次へ進む。
- 難易度で弾数・弾速・発射間隔を変える(Easy 0.6倍 / Normal 1.0倍 / Hard 1.4倍 / Lunatic 1.8倍 が目安。弾速は密度ほど上げない)
- 難易度が変わっても、スペルの意図(安全地帯や隙間の作り方)は保つ
- 本ボスの最終フェーズ終了時は小Pと弾消しの点を出さず、白演出から撃破後会話へ進む。報酬は会話後の退場時に配る

## 会話

本ボス・中ボスとも、戦闘前会話の前にフィールドへ登場する。

- 道中の敵・敵弾・自機弾を消してから、画面上端の外から60フレームかけて定位置へ降りる。到着後20フレーム静止して会話を始める
- 登場開始時に道中の被弾猶予を取り消す。登場中は自機移動だけを許可し、射撃・ボム・被弾を止める。無敵時間は減らす。背景はスクロールを続ける
- ミネルヴァは動画後の白フェード150フレームと白保持60フレームを経て登場する。登場開始から120フレームで白を消す
    - ミネルヴァの登場演出は白明けが完了する120フレームまで続け、その後で会話を始める
    - ポーズ中は白の不透明度を保つ。ポーズメニューは白フェードの上に表示する
- 本ボス撃破後は120フレームの白明けで対峙へ戻してから会話する。ボスは定位置に立ったまま降下しない。`?boss=&phase=` の直行と練習も同じ流れを使う

ボス戦前・撃破後・中ボス登場時に会話を出す。自機はみみこのみ。台詞は各キャラクターの人格・口調に合わせる。

- 迅雷の撃破後会話は次の4行にする

## デバッグ・検証用の口

受け入れ検証をブラウザの自動操作で行うため、次の口を用意する。

- URLクエリ
    - `?stage=<1|2|3|4|5>`: そのステージの道中から始める
    - `?stage=<1|2|3|4|5>&from=boss`: 中ボスを終えた扱いで、本ボス登場の120フレーム前から始める。開始時の題字と暗幕は省く
        - 4面: 迅雷撃破 → 白 → jinrai-gift動画 → 対峙 → 撃破後会話 → 餞別 → 退場 → クリアを確認できる
        - 5面: 白フェード → lastboss動画 → 白フェード150フレーム → 白保持60フレーム → 白明け120フレームとミネルヴァ登場 → 会話 → 戦闘 → 撃破 → 白 → minerva-finale動画 → 対峙 → 撃破後会話 → 退場 → クリアを確認できる
    - `?boss=<1|2|3|4|5>&phase=<n>`: そのボスのn番目のフェーズ(0始まり。通常・スペルを通し番号)から始める。会話は飛ばす
        - `?boss=5&phase=10`: 最終フェーズから始め、撃破後の白・minerva-finale動画・対峙・撃破後会話・退場・クリアを確認できる
    - `?boss=<n>&phase=<k>&hp=<0〜1>`: 開始フェーズの残り体力を最大HPの指定割合にする
        - `?stage=<n>&from=boss&hp=<0〜1>`: 本ボスの最初のフェーズに同じ割合を適用する
        - 範囲外は0.01〜1に丸める。省略時と数値が無効な場合は満タン
        - 後続フェーズは満タン。HP連動の攻撃は指定した残り体力から判定する
    - `?player=mimiko&difficulty=<easy|normal|hard|lunatic>`: 選択画面を飛ばす。ほかの`player`値は無効
    - `?invincible=1`: 自機が被弾しない
    - `?autoshot=1`: Zを押し続けている扱いにする
    - `?power=<0〜5>&lives=<0〜8>&bombs=<0〜8>`: 開始時のPower・残機・ボム数を指定する。範囲外は端の値に丸める
    - `?stage=1&power=5&maxform=1`: 最高形態で開始する検証用クエリ。Power5未満では最高形態にならない
    - `?bgm=0`: BGMと動画の音を無効にする
    - `?ending=mimiko`: エンディングから始める
    - `?movie=<opening|lastboss|jinrai-gift|minerva-finale|ending>`: 指定の1本だけを再生する
        - 終了・スキップ・失敗後: openingは1面、lastbossはミネルヴァ登場と5面ボス前会話、jinrai-giftは白演出・対峙・4面撃破後会話・餞別・退場、minerva-finaleは白演出・対峙・5面撃破後会話・退場・クリア、ending系はエンディングへ進む
- `window.__owlery`(開発ビルドのみ)
    - BGMの `bgmVolume` はOption音量・ポーズ倍率・演出倍率を掛けた目標音量。クロスフェード途中の実ゲインは含まない
    - `state()`の演出用フィールド: 動画名 `movie`、道中時計 `stageFrame`、題字時計 `stageIntroFrame`、登場時計 `arrivalFrame`、フェード名 `transition`、フェード時計 `transitionFrame`、白の不透明度 `whiteAlpha`、餞別時計 `giftFrame`、未回収の餞別数 `giftItems`、攻撃時計 `phaseFrame`、行送り時計 `endingFrame`、ロール時計 `creditsFrame`
        - 退場時計 `departureFrame`、未回収アイテム数 `items`、BGMの演出倍率 `bgmMultiplier` も確認できる
        - 動画以外では `movie` は `null`、フェード外では `transition` は `null`
    - `state()`: 現在のシーン名、ステージ、ボス名、中ボスかボスか、フェーズ番号、スペル名、残り時間の秒数 `phaseRemainingSeconds`、残り体力の割合 `phaseHpRatio`、弾数、スコア、Power、最高形態 `maxform`、残機、ボム、FPS、BGM cueを返す。フェーズ外は残り時間と残り体力の割合がともに `null`。`maxform` は通常時0、最高形態で1
    - `skipPhase()`: いまのボスのフェーズを撃破扱いで進める
- 画面左下にFPSを小さく出す(開発ビルドのみ)

## テスト

- ユニットテスト(Vitest): 当たり判定、グレイズの判定(1発1回まで)、喰らいボムの猶予、アイテム自動回収の条件、点アイテムの価値計算、エクステンドの閾値、ハイスコア保存のlocalStorage失敗時の縮退、難易度倍率の適用
- 受け入れ検証(E2E)は発注元(チャッピー)が行うので、E2Eテストは書かなくてよい
