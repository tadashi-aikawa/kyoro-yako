# 梟楼夜航 — きょうろうやこう 仕様

owleryのAIメンバーとエトキチが登場する、縦スクロールの弾幕シューティング。みみこを操作してブラウザで遊ぶ。

## 技術

- Vite + TypeScript(strict)+ Canvas 2D。フレームワーク・ゲームエンジンは使わない
- pnpm。Biome(recommended。`noNonNullAssertion` / `noExplicitAny` はoff)。テストはVitest
- `pnpm check` で typecheck + lint + test + build をまとめて通す
- ファイル名はkebab-case。モジュールは責務ごとに小さく分ける
- 論理座標は640x480固定。表示はウィンドウに収まる最大の実数倍で中央に置く。canvasの実ピクセルは表示倍率とdevicePixelRatioを掛けたサイズにし、`setTransform` で論理座標に合わせる。画像補間は高品質にする
- 固定タイムステップ60fps。描画はrequestAnimationFrame、更新は累積時間で1/60秒ずつ回す(1フレームあたり最大4ステップまで)
- 弾・敵・アイテムはオブジェクトプールで管理し、画面内の弾2000発でも60fpsを保つ
- 弾のスプライトは種類×色ごとにオフスクリーンcanvasへ実ピクセル倍率で描き、表示倍率変更時に再生成する。glowもキャッシュへ焼き込む

## 画面レイアウト

- 左: プレイフィールド 384x448。左上 (32,16)
- タイトル: 左にゲーム名・物語の導入・出発メニュー、右に5階の梟楼とみみこを描く。ジャンルは「弾幕シューティング」。
- 右: みみこの冒険ノート。5面の道のり、今回のスコアと最高記録、現在の自機を含めた残り回数、ボム数、ショット強度、かすり回数、点アイテムの最大価値を表示する。
- 残り回数とボムは数値、ショット強度は4段階のバーと数値で表す。下部にみみこの顔と記録の言葉を置く。
- 背景: 各階の床と建築を多層で縦スクロールする。手前の柱・書架・額縁・桜・天文台の構造も画面外まで流し、奥の層は遅く動かす。必殺技中は暗い背景とボスの色の魔法陣を重ねる。

## 操作

| キー | 動作 |
|---|---|
| 矢印キー | 移動(斜め移動は正規化) |
| Shift | 低速移動。自機の当たり判定の点と、周囲の薄い円を表示する。ショットが集中型に変わる |
| Z | ショット(押しっぱなしで連射)/ メニュー決定 / 会話送り |
| X | ボム / メニュー戻る |
| Esc | ポーズ(再開 / タイトルへ戻る / やり直し) |
| Ctrl | 押している間、会話を早送り |

## 素材

- `public/assets/members/<slug>-face.webp`(540x540、透過)と `<slug>-stand.webp`(多くは縦長。mimikoとetokichiは正方形)
- `public/assets/sprites/<slug>.webp` はフィールド用の透過SDスプライト。未配置・読み込み失敗時はstand画像へ縮退する
- slug: neo / minerva / mimiko / obsidia / jinrai / claudine / chappy / etokichi
- 用途
    - 自機・ボス・中ボスのフィールド上の姿: sprite画像を描く(自機は高さ約40px、ボスは高さ約64px)。緩やかな上下動と左右移動時の小さな傾きを付ける。ボスの背後に回転する魔法陣を描く
    - 会話: stand画像を左右に大きく出す(左=自機、右=ボス)。話していない側は暗くする
    - スペルカットイン・タイトル・エンディング: stand画像。カットインの高さは論理座標で360px以上
    - 自機選択画面・サイドパネル: face画像。現在は自機1人なので選択画面を飛ばす
    - エトキチの正方形stand画像は、会話とカットインで横幅を広く取り、ほかの人物と見た目の大きさを揃える
- 雑魚敵はowlery(フクロウ小屋)にちなんだ**小さなフクロウ**。画像を使わずcanvasで描く(丸い胴・大きな目・耳羽。色違いで種類を分ける)。羽ばたきは簡単な2コマでよい
- 効果音はWebAudioでその場で合成する(ショット・被弾・グレイズ・敵撃破・ボム・スペルカード宣言・スペル取得・アイテム取得・エクステンド)
- 音量はタイトルの設定で0〜100%(既定50%)。localStorageへ保存する(アクセス失敗時は既定値で動く)

### BGM

- 曲ファイルと場面の対応は `docs/bgm.md` に従う。MP3は `public/assets/bgm/` に配置する
- メニューはtitle、道中と中ボスは各ステージ曲を流す。ボス戦前会話から撃破後会話までは各ボス曲を流す。ステージクリアでは停止し、エンディングとスタッフロールはendingを流す
- 曲の切り替えは約1秒のクロスフェードでつなぐ。デコード後の波形から、先頭と末尾に0.3秒以上続く-45dBFS未満の無音を曲ごとに検出して除く。0.2秒以下の短い音が無音を分断する場合は一続きの無音として扱う。ループは有音区間の末尾約2秒と頭をクロスフェードでつなぐ。ポーズ・ゲームオーバー中は音量を下げる
- 最初のキー入力後に再生を開始する。必要になった曲だけ取得・デコードして使い回す。未配置の曲は無音で進める
- Optionで効果音とBGMの音量を別々に設定する。BGMの既定は60%。どちらもlocalStorageへ保存し、失敗時は既定値で動く

## ゲームの流れ

タイトル → 難易度選択(Easy / Normal / Hard / Lunatic) → ステージ1 → 2 → 3 → 4 → 5 → エンディング → スタッフロール → タイトル

- タイトルのメニュー: Start / Practice(クリア済みのステージを選んで遊ぶ。未クリアなら1のみ)/ Option(音量)/ 操作説明
- ハイスコアは難易度ごとにlocalStorageへ保存する
- ステージの間に「Stage Clear」と、クリアボーナス(ステージ番号×100万+残機・ボム・Power・Point・Grazeによる加算)の画面を挟む

## 自機

| 自機 | 通常ショット | 低速ショット | ボム |
|---|---|---|---|
| みみこ | 追尾するフクロウの羽。威力は低め | 追尾を弱めて前方へ束ねる | 書いて残す七重の頁: 自機を中心に広がる7重の輪。敵弾を消して敵にダメージを与える |

- 自機定義は配列で管理する。2人以上になれば自機選択画面を表示し、1人の間は難易度選択から直接1面へ進む
- 当たり判定半径 2.5px、グレイズ判定半径 18px。低速時の移動速度は通常時の約45%
- Powerは0.00〜4.00(小Pで+0.05、大Pで+1.00)。1.00ごとにオプション(自機の周りの小さな光球)が1つ増え、ショットが強化される
- 残機は初期2、画面には自機を含む3回と表示する。
- ボムは初期3個、所持上限8個。
    - 被弾時: 3個未満なら3個へ回復する。3個以上なら所持数を保つ。
- 被弾するとPowerが最大1.00減る。
    - 回収品: 失った量に相当する小Pをフィールドの広い範囲へ分散する。1.00なら20個、小Pは0.05単位で切り捨てる。
    - 回収: 上部への移動では一括回収しない。近づいた小Pだけ吸い寄せる。
    - 猶予: 被弾後の約8フレームは**喰らいボム**を使える。この間にXでボムを撃つと被弾を取り消す。
- 被弾後・ボム中は無敵(被弾後は約3秒点滅)
- エクステンド: スコア 1000万・2000万・4000万・6000万で残機+1
- 残機が尽きたらゲームオーバー。コンティニュー(スコアを0にして同ステージの最初から。回数無制限)するかタイトルへ戻るかを選ぶ

## アイテム

- 小P(赤)・大P(赤大)・点(青)・ボム(緑)・1UP(ピンク)
- 自機が上端ライン(フィールド座標 y < 112。上から1/4)より上にいる間は、画面中のアイテムを自動回収する
    - 例外: ボスの補充品と被弾時の小Pは手で拾う。
- 低速移動中はアイテムの吸い寄せ範囲が広がる
- 点アイテムの価値は取得した高さで変わる(上端ラインより上で最大値)。最大値は「Point」(初期1万)で、グレイズ数に応じて増える
- ボス撃破時・スペル取得時は画面の弾を点アイテムに変えて自動回収する
- ボスの各フェーズ終了時に小P10個を散布する。
    - 回復量: 全部拾うとPowerが0.50増える。
    - 追加品: ボム1個が30%、ライフ1個が2%、追加なしが68%。ボムとライフは同時に出ない。
    - 条件: 撃破でも時間切れでも支給する。中ボスの時間延長では支給しない。
    - 配置: ランダムに離れた位置へ散らす。上部へ移動しても一括回収せず、近づいて拾う。
    - 戦闘終了後: 中ボスと本ボスの最後に3秒の回収時間を設け、その後に会話や道中へ進む。
    - 理由: 会話中に停止する前に手動で回収できるようにするため。

## ステージ構成

各ステージは道中(雑魚フクロウの編隊)→ 中ボス → 道中後半 → 会話 → ボス → 会話(撃破後)で構成する。

- ボス前会話までの道中と中ボス戦は約90〜110秒。5面はネオの延長回数に合わせて道中後半を調整する。雑魚は上半分で留まるか曲がって横または上へ退場する。射撃は入場30フレーム後かつ自機から150px以上離れている時だけ
- 道中の編隊は弧を描く列、引き返す列、花弾を落とす横断群、自機狙い3way、単発狙い弾の掃射列、中央の全方位隊に、左右の挟み込み・蛇行・旋回・V字隊列を加えた10種。面と前後半で順序を変える。練習時にも同じ順序を再現する。
- 同時に最大18体を見せる。新しい編隊の動きを見せる間は追加の交差隊を重ねない。挟み込みは内側へ斜めの扇、蛇行は方向の違う連射、旋回は輪からの扇、V字隊列は時差のある狙い弾を撃つ。後の面ほど弾と編隊を増やす。
- Power 0で倒しやすい体力にする。Normalの道中は各ボスの最初の通常攻撃より避けやすくする

### ボスの構成

1〜5面は通常攻撃とスペルカードを前半で交互に出し、終盤のスペルを連続で出す。体力バーはボス名の横に出し、残りのスペル数を★で示す。中ボス戦の★は中ボス自身の残り1枚を示し、撃破中は0になる。5面ネオの延長中も1のまま。

| ボス | 通常攻撃とスペルカード(順番どおり) |
|---|---|
| ネオ | 通常1 → 全画面キーバインド → 通常2 → このキーボード、いいでしょ！ → 通常3 → dotfilesの沼 → Enterで一斉送信 |
| オブシディア | 通常1 → 必要ないものは消す → 通常2 → Wikiリンクの網 → 通常3 → タグの引力 → ミニマリストの一掃 |
| 迅雷 | 通常1 → 跳ね返る千本手裏剣 → 通常2 → 夜桜の簪 → 通常3 → 稲妻の予告線 → 通常4 → 夜桜の舞 → 花吹雪 → 迅雷一閃 |
| クロディーヌ | 通常1 → 削ぎ落とされた美 → 通常2 → タイポグラフィの雨 → 通常3 → グリッドシステム → 通常4 → 補色の対比 → ホワイトスペース → よろしければ、また |
| ミネルヴァ | 通常1 → 七重の調査網 → 通常2 → 矛盾を突く一手 → 通常3 → 反証可能性 → 通常4 → 梟の目 → 通常5 → その結論、撤回します → 孫引きの連鎖 → インタビューの間合い → 梟は暁に飛び立つ |
| エトキチ(中ボス) | エトワールの輪 |
| ネオ(5面中ボス) | 「最後」と言ってからが長い |
| チャッピー(中ボス) | Codexへの丸投げ |

通常攻撃の弾幕の意図:

- ネオ「連打のリズム」: 自機狙いの短い3連バーストと、薄い星弾の格子を重ねる。通常2は連打の間隔を少し長くする。1面は最も易しくする。
- オブシディア「整列」: 自機が通れる間隔の横一列の文字弾を、左右へ斜めに進める。2色を交互に使い、列を重ねて密度を出す。通常2は2列を短い間隔で続ける。
- クロディーヌ「対称」: 左右対称の素直な花弁アークと全方位リングを2色交互に連ねる。特定の安全地帯を追わせず、均等な弾間を抜ける。
- 迅雷「速度」: ボス位置から他ボスより速い針弾を全方位へ連射する。自機狙いの扇は1周期に1回だけ混ぜる。短いアタックの強い専用SEを発射に同期する。
- ミネルヴァ「星の重奏」: 現在の自機位置を狙う星弾の扇と、全方位の星弾リングを交互に放つ。停止や再照準を使わず、最も密度の高い直進弾幕にする。

全難易度で斉射の弾間を保ち、発射周期で密度を増やす。

Normalの通常攻撃は道中の1.1倍以上、弾数・通過量とも旧版の通常攻撃以下とする。道中との比較は迅雷だけ通過量、他の4体は画面内平均弾数を使う。

オブシディアの列とネオの星格子は、画面上外のy=-8から発射する。

スペルカードの弾幕の意図(実装はこの意図を満たせば自由):

- エトワールの輪: 傾いた楕円軌道を星弾が回る。光った星が順に輪からこぼれ、重力で落ちる
- 全画面キーバインド: 3段のキーボード配列から光ったキーだけが一拍後に真下へ落ちる
- このキーボード、いいでしょ！: 自機を囲む切れ目のあるキーキャップの輪が縮み、止まって外へ弾ける
- dotfilesの沼: 紫の沼に入った弾と自機が減速する。輪郭を点滅させて領域を予告する
- Enterで一斉送信: 左から1発ずつ並んだ文字弾が、↵の点灯後に横一列で落ちる
- 「最後」と言ってからが長い: 5面中ボスのネオは時間切れのたびに「最後にもう一つだけ！」と言って時間を延長する。最大3回まで。延長1は全画面キーバインド、延長2はこのキーボード、いいでしょ！、延長3はdotfilesの沼。体力を削ればすぐ撃破できる
- 書棚の呼吸: 左右それぞれ6段から3段ずつ交互に背表紙が光り、幅約40%まで本棚が突き出てから引っ込む。先端から小弾が3発こぼれる
- 必要ないものは消す: 全方位のリングで光る一部の弾が点滅後に消え、通り道が開く
- Wikiリンクの網: ノード間に細いリンクが予告表示後に実体化し、網目がゆっくり降りる
- タグの引力: 3色の魔法陣が出現し、同じ色の弾が対応する陣へ曲がる
- ミニマリストの一掃: 発散地点へ移動し、専用の集中ポーズで胸元へ紫の光を集め、周囲へ全方位の弾幕を3連続で放つ。
  - Normal: 5秒周期、0.6秒の移動、1.3秒の溜め、0.2秒間隔で36発ずつ発散。専用SE・短い閃光・円形の衝撃波を発射に同期する。
  - 変化: 毎回位置を変え、同心輪・逆方向へ曲がる星弾・楕円状の丸と針の混合弾を巡回する。固定の安全通路は設けず、溜めの間に距離を取り、広がる弾の間を抜ける。
- 跳ね返る千本手裏剣: 扇状の予告線の後、大きな手裏剣が左右の壁で一度だけ跳ね返る。反射時に小弾を3発撒く。戻る軌道の内側へ潜る
- 夜桜の簪: 放射状の細い予告線が難易度に応じて約0.7〜1.25秒後に太いレーザーへ変わり、ゆっくり回る。間に低速の花びらが舞う。回転に合わせて隙間を追う
- 稲妻の予告線: 自機位置に黄色い魔法陣と縦の予告線を表示する。難易度に応じて約0.6〜1秒後に縦レーザーが落ち、着弾点から小弾が円形に散る。横へ動く
- 夜桜の舞: 迅雷の周囲と画面上端から、桜色3色の花びらが落ちる。花びらごとに揺れ幅・周期・落下速度・回転を変え、見た目より細い判定の隙間を縫う。約5秒ごとに左右ランダムの突風が吹く。風上から流れる細い風の筋で予告し、花びらを風下へ流す。収束時には風下の花びらが小さく渦を巻く。風の筋が見えたら風上側へ寄る
  - 花びら: EasyからLunaticの順に15・12・10・9フレーム間隔で3・4・5・6発を追加する。落下速度は毎フレーム0.75〜1.35・0.95〜1.55・1.15〜1.75・1.35〜1.95px。揺れ幅は8〜25px、揺れ周期は毎フレーム0.025〜0.07rad、回転速度は毎フレーム0.018〜0.063rad。判定半径は2.2px
  - 突風: 300フレーム周期。予告はEasyから順に84・60・48・36フレーム。風圧は90フレーム続き、最大の横移動量は毎フレーム1.1・1.8・2.4・3.0px。風下の端で24フレーム渦を巻く
- 花吹雪: 迅雷を起点に全方位へ花びらを撃ち続ける。発射角が少しずつ回り、螺旋の花吹雪が周囲へ広がる。螺旋の腕の間を抜ける
- 迅雷一閃: ボスが横断経路を線で予告した後、高速で横切る。
  - 高さ: 上寄り・中ほど・やや下の3段を巡回し、初期自機位置より少なくとも120px上に留める。
  - 弾列: 通り道へ約16px間隔で20発を置き、2発分の切れ目を1か所作る。
  - 発射: 列は停止後に全体が一瞬光り、自機へ向き直って端から時間差で飛ぶ。
  - 後半: 体力が半分以下になった次の巡回から、横断を往復2連続にする。
  - 中央発散: 開始15秒から8秒ごとに横断を中断する。煙で消え、0.3秒後に画面中央へ瞬間移動する。専用の忍術印ポーズで0.5秒光を溜め、雷と花びらを3回放射する。各発散に画面全体へ広がる枝付き稲妻と鋭い放電・雷鳴SEを同期する。Normalは1回56発。切れ目を残し、消失・発散・帰還の2秒後に横断を再開する。
- 花影: 煙の後に中ボスが3体へ分かれる。本体だけ金色の魔法陣があり、命中時は煙とともに本体の位置が変わる。3体とも低速の花びらを撃つ

- 削ぎ落とされた美: 壁の一部が点滅後に消え、できた縦の余白を残して壁が降る
- タイポグラフィの雨: 欧文・和文・記号の12文字をセリフ・斜体サンセリフ・等幅の3書体で降らせる。
  - 天候: 4秒ごとに小雨・豪雨・台風を巡回する。豪雨は速さと密度を増し、台風は横風・揺れ・回転を加える。風上の壁からも文字が流れ込む。次の台風は逆向きに吹く。切り替え前0.75秒に次の天候を表示する。
  - Normal: 小雨は14フレームごとに3発、豪雨は5フレームごとに4発。台風は4フレームごとに上端から5発、風上の壁から1発。文字の判定半径は2.4〜3.6px。
- グリッドシステム: 均等列・可変幅・可変行・千鳥配置へ切り替わる。
  - 配置: 薄い格子状の弾を予告し、予告後に一斉に実体化する。配置を保ち、下・右・上・左へ順に流れる。自機を追わず、発射直前に移動方向の短い矢印を表示する。

- ホワイトスペース: 弾の地模様の中に動く円形の余白があり、円の内側の弾が消える
- よろしければ、また: 耐久スペル。S1〜S5を10秒ずつ軽く再演する。残り約8秒はクロディーヌがゆっくり会釈し、予告した花形の弾の輪を2回放つ。最後の輪は時間切れ前に画面外へ出る

- Codexへの丸投げ: 箱が着地点へ飛び、3・2・1の表示後に開いて小弾が全方位へ散る。開くと「完成しました。ご確認ください。」が表示される

- 矛盾を突く一手: 放射状に飛んだ弾が止まって疑問符を作り、自機へ向き直って飛ぶ
- 反証可能性: 左右の2つの弾道を予告し、明るさが脈打つ片方だけを実体化させる
- 梟の目: 視線が等速で往復する。視線の当たる弾は止まり、外れると動く
- その結論、撤回します: 一度撃った弾がボスへ戻り、向きを変えて撃ち直される
- 孫引きの連鎖: 点滅した大弾が2つへ分かれ、子弾も点滅して2つへ分かれる。三代目で止まる
- インタビューの間合い: 自機を追うボスが間合いの下限を保つ。周囲の弾の輪は近いほど濃くなる
- 梟は暁に飛び立つ: 耐久スペル。羽ばたくフクロウを模した弾の編隊が朝焼けの空を横切る。
  - 残り45秒: ボスの背後の上半面へ継続的に金色の針弾を放ち、上端の安全地帯を塞ぐ。
  - 残り30秒: その場で停止して目を閉じ、両手を合わせて祈る。金色のオーラを1.2秒溜め、その位置から3秒間、高密度・高速の渦をマシンガンのように連射する。その後は1.8秒休止し、6秒周期で繰り返す。渦の回転方向は周期ごとに反転する。
    - Normal: 3フレームおきに7方向へ毎フレーム3pxの光弾を放ち、連射1回で420発。判定半径は2.3px。
    - ポーズ: `public/assets/sprites/minerva-prayer.webp` を溜めから連射終了までの4.2秒間使う。休止で通常の姿へ戻る。

### スペルカードの共通仕様

- 宣言時にボスのカットイン(stand画像が画面を斜めに横切る)と、右上にスペル名の帯を出す

- 通常攻撃は40秒、本ボスのスペルは60秒、中ボスは45秒。5面のネオは最大3回延長する。耐久スペル以外の時間切れは取得失敗扱いで次へ進む

- 難易度が変わっても、スペルの意図(安全地帯や隙間の作り方)は保つ

## デバッグ・検証用の口

受け入れ検証をブラウザの自動操作で行うため、次の口を用意する。

- URLクエリ
    - `?stage=<1|2|3|4|5>`: そのステージの道中から始める
    - `?boss=<1|2|3|4|5>&phase=<n>`: そのボスのn番目のフェーズ(0始まり。通常・スペルを通し番号)から始める。会話は飛ばす
    - `?player=mimiko&difficulty=<easy|normal|hard|lunatic>`: 選択画面を飛ばす。ほかの`player`値は無効
    - `?invincible=1`: 自機が被弾しない
    - `?autoshot=1`: Zを押し続けている扱いにする
    - `?power=<0〜4>&lives=<0〜8>&bombs=<0〜8>`: 開始時のPower・残機・ボム数を指定する。範囲外は端の値に丸める
    - `?bgm=0`: BGMを無効にする
    - `?ending=mimiko`: エンディングから始める
- `window.__owlery`(開発ビルドのみ)
    - `state()`: 現在のシーン名、ステージ、ボス名、中ボスかボスか、フェーズ番号、スペル名、残り時間の秒数 `phaseRemainingSeconds`、残り体力の割合 `phaseHpRatio`、弾数、スコア、Power、残機、ボム、FPS、BGM cueを返す。フェーズ外は両値とも `null`
    - `skipPhase()`: いまのボスのフェーズを撃破扱いで進める
- 画面左下にFPSを小さく出す(開発ビルドのみ)

## テスト

- ユニットテスト(Vitest): 当たり判定、グレイズの判定(1発1回まで)、喰らいボムの猶予、アイテム自動回収の条件、点アイテムの価値計算、エクステンドの閾値、ハイスコア保存のlocalStorage失敗時の縮退、難易度倍率の適用
