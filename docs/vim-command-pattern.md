# ネオのVimコマンド弾幕

「ノーマルモードから逃がさない」は、短いコマンド予告の後に、その意味を持つ通常弾を発射する。

| コマンド | 弾幕 |
|---|---|
| `3j` | 下向きの扇を3連射する |
| `3j2hyyp` | 3連射を左へ2段ずらし、移動後の3連射を1組コピーする |
| `2h` | 扇が左へ2段移動する |
| `2lyy2p` | 扇が右へ2段移動し、移動後の扇を2回コピーする |
| `yy3p` | 最初の扇を3回追加でコピーする |
| `2hyy3p` | 扇が左へ2段移動し、移動後の扇を3回コピーする |
| `2l` | 扇が右へ2段移動する |
| `3jdd` | 3連射の先頭の扇を消し、後続を残す |
| `dd` | 2連射の先頭の扇を消し、後続を残す |

- コマンド間隔は210フレーム。
    - 時間: 60fpsで3.5秒。
- 予告はEasyから順に72・60・48・40フレーム。
- 予告中はコマンドの1文字列と短い時間表示だけを描く。
- 弾はキャッシュ済みの通常スプライトを使う。
    - 描画: 弾ごとの文字や動的な影を付けない。
- コピーは最初の発射位置と速度を使う。
    - 横移動後: 発射位置も同じ距離だけずらしてコピーする。
    - 照準: コピーのたびに自機を狙い直さない。
- ボム・被弾・技終了で、その波の予告と後続射撃を中止する。
- ポーズ中は止まる。
- 5面ネオの再演でも同じ攻撃を使う。

検証ではコマンドの回数・方向・コピー元・消去対象を確かめる。

Chromeでは4難易度の回避と撃破を確かめる。描画時間は高解像度でも比較する。
