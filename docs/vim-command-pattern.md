# ネオのVimコマンド弾幕

「ノーマルモードから逃がさない」は、コマンド全文の予告後に行の編集を再現する。

- 各コマンドの初期配置は7行。
    - 切替: コマンドごとにリセットする。
    - 上限: 行間24pxで最大10行。最下段はy=320。
- 左端のキーに行番号を表示し、選択行にカーソルを置く。
- `5Gyy3p`、`3Gyy2p`、`4G2dd`、`2Gyy3p`、`6Gdd`を順に使う。
- `nG`でn行目へカーソルを移す。
- `yy`でその行の弾を選択する。
- `3p`は選択行と同じ弾の並びを下へ3行追加する。
    - 結果: 後続の既存行も下へずれる。
- `2dd`は現在行から2行の弾を削除する。
    - 結果: 後続の行を上へ詰める。
- 編集中の弾は無害。
- 編集完了後、全行が一斉に落下して攻撃になる。
- 全文を予告し、実行中の部分だけ明るくする。
- 複製先の行は追加前に輪郭を表示する。
- 行ごとに穴を少しずらす。
    - コピー: 同じ穴が連続する。
    - 削除: 穴の段差が詰まる。
    - 制約: 隣接する穴を移動できることを全難易度の試遊で確かめる。
    - 難易度: Easyでは全行に共通する穴を許す。Normal以上は1波の全行を静止して抜ける通路を残さない。
- 穴の位置と傾きは波ごとに変える。
- 難易度は予告時間、穴幅、落下速度で変える。
    - 共通: Vimの意味は変えない。
- 5面ネオの再演も同じ仕組みを使う。
- 1コマンドは540フレーム。
    - 周期: 5コマンドを45秒で一巡する。
    - 切替: 落下した弾が画面外へ抜けてから、次の編集を始める。
- 編集中の弾は半透明で点滅する。
- 落下直前24フレームは▼を表示する。
- 落下時には不透明になり発射音を鳴らす。
- ボムで消した波の編集表示も消す。
    - 単位: 1コマンドを1波とする。
    - 対象: 弾、全文、行番号、カーソル、複製先の輪郭。
    - 復帰: 次の540フレーム周期で新しいコマンドを始める。消した元行の複製は生成しない。
- ポーズ中は進めず、技終了で表示も消す。

受入: 実際の行数・コピーした配置・削除後の詰め・予告中の無害性・ボム・ポーズ・5面再演を検証する。Chromeで全難易度の回避、射撃撃破、描画を確かめる。

コマンドの参照: [Vimの移動](https://vimhelp.org/motion.txt.html#G)、[Vimのコピー・貼り付け・削除](https://vimhelp.org/change.txt.html#p)。
