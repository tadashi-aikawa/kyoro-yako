# レスポンシブ・ブルーム

クロディーヌの最終スペル。制限時間99秒、HP2916。ショットとボムで削り、HP0で撃破する。

- 開始演出: 既存の胸に手を添えたポーズを保ち、2秒かけて静かに目を閉じる。
    - 順序: 閉眼 → 100フレームのカットイン → 3秒かけて開眼 → 花火。
    - 固定: 導入の間は位置・サイズ・傾きを固定する。浮上と手を開くポーズは使わない。
    - 通常動作: 花火開始後は通常の待機・左右移動・弾出しスプライトへ戻る。
    - 保護: 開眼が終わるまで無敵。花火開始後は通常のダメージを受ける。
- エリア: 横長・縦長・正方形・縦長・横長・全画面の順に繰り返し変形する。
    - 予告: 次のエリアを1.2秒間、破線で示す。
    - 変形: 2.5秒かけて滑らかに変形する。
    - 座標: 自機・花火弾・ボスへ同じ変換を適用する。エリアの外へは移動できない。
- 小花火: 無害な芯が下から昇り、3層の菊花や扁平なリングへ開く。
    - 打ち上げ音: 0.86秒かけて音程が上がる「ヒュー」という専用SEを鳴らす。
    - 発射停止: ボム中と終了まで90フレーム未満の間は新しい花火を打ち上げない。
    - 予告: 開花直後の18フレームは無害にする。
    - 弾道: 広がりながらゆるく垂れる。自機を追尾しない。
    - 消滅: 下端に到達したところから減速し、止まる高さを少しずつ変えて枠内で90フレームかけて薄れる。最後の32フレームは無害にする。
    - 難易度: 1層20・26・32・38発。発射周期は156・132・114・96フレーム。
- 大玉の柳: 小花火の斉射を8秒で止め、2秒の間を置いてから高く打ち上げる。
    - 周期: 24秒周期。撃破しない場合は99秒の間に4回打ち上げる。
    - 打ち上げ: 1.6秒かけて上空へ昇る。小花火より低い音程から長く上がる専用SEを使う。
    - ボム中の予定: 打ち上げ前にボムを使った場合は予定を捨てず、ボム明けから約0.8秒置いて打ち上げる。
    - 開花: 低い「ドーン」という専用SEで大きく開き、横への広がりを減速する。
    - 降下: 金色に橙を交えた長い光跡を残す。開花直後を過ぎた降下速度は最大1px/フレームに抑える。
    - 光跡: 過去120フレーム分の軌道を、変形後のエリアに合わせて描く。光跡は無害で、明るい先端にだけ判定がある。
    - 弾数: 1層28・36・44・52発の3層。
    - 消滅: 下端への到達後に減速し、止まる高さを少しずつ変えて枠内で150フレームかけて薄れる。最後の53フレームは無害にする。全ての弾を14秒以内に回収する。
    - 再開: 柳が消えた後、またはボムで大玉を消した後は、次の拍から小花火を再開する。
- 終了: HP0または99秒の時間切れで残弾を消し、撃破演出と戦闘後会話へ進む。
    - 取得: 無被弾・ボム未使用でHP0にすると記録ボーナスを得る。時間切れは取得失敗。
    - 音源: ボム・ポーズ・フェーズ終了で、発音済みの花火SEも止める。

旧「よろしければ、また」の5技の再演と、最後の「では、遠慮なく。」の薔薇弾幕を置き換える。
