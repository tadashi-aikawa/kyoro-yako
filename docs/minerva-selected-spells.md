# ミネルヴァの再調整と採用した新技

## サーベイとリトラクションの差し戻し

- サーベイの広い共通通路、通路を作る弾の削除、通路の点線を撤去する。
- 七重の円形の輪と、各輪にある小さな切れ目を保つ。収縮後に輪の中心から放射状に広がりながら落下する。
- リトラクションは角度による間引きをなくし、全周へ等間隔で放出する。弾と弾の自然な隙間は保つ。
- リトラクションの画面内での一拍停止、同じ原点への帰還、帰還後の消去は維持する。

## ソクラティック・メソッド: 推論の門

- 4つの記号の対応表を示す。問いは「この記号を2回変換すると？」とする。
- 対応表を4行にし、答えを求めるには2段たどる必要がある。対応表は問いの間ずっと表示する。
- 画面幅を3列の門に分け、異なる記号を示す。正解の門は広く空け、不正解2列に予告付きの格子弾を実体化して落とす。
- 不正解でも即死の壁にはしない。弾と弾の自然な隙間を残し、回避で立て直せるようにする。
- Easyは考える時間と実体化までの時間を長くする。色だけで判別させない。
- 考える間にも少量の遅い自機狙い弾を流す。ボム中は新しい弾を生成しない。

## グラビティ・シフト

- 旧デコイを技名と仕掛けごと廃止する。ユーザーの別案を採用する。
- 自機狙いの扇、回転する輪、星の雨を交代で放つ。
- 8秒ごとに、予告後の一定時間だけ重力が自機を上下左右のいずれかへ押す。
- 押す力は低速移動より小さくし、低速でも反対方向への入力で抗えるようにする。自機の移動入力を無効にしない。
- 矢印で方向を明示する。予告中に重力はかけない。方向は発動中に変えない。上向きの力は他の方向の65%に抑える。
- 弾は重力の影響を受けず、自機だけが流される。ポーズと技終了で重力を止める。

## オウル・オブ・ミネルヴァ: 夜明けの星図

- 祈って溜め、渦を発散する攻撃は、溜め72フレーム・発散180フレーム・休止108フレームのまま残す。
- 他の横断編隊・上向きの針・ランダムな接触フクロウを廃止し、7つの無害な大きい星で梟の翼を描く。
- 星の点滅と短い矢印で発射する順番と方向を示し、星ごとに羽の扇を撃つ。狙いは予告開始時に固定し、その後は追尾しない。
- 星図の8秒と祈りの6秒を交互に繰り返す。重ねて発動しない。
- HPに応じて3段階。星図の翼を狭めて縦へ開き、傾き・発射順・扇の密度を変える。生成済みの星を突然動かさない。
- 時間表示は∞。時間切れでは終わらず、HPを削り切った場合にだけ回収とエンディングへ進む。
- 体力はPower4で撃ち込み続けて約60秒を目安とする。祈りの溜め・発散中もダメージを与えられる。
- 既存のクロディーヌの耐久スペルには影響させない。
- 星図の発射源、予告、弾はボム・技終了で消す。ボム明けに既に終わった一斉射をまとめて撃たない。
