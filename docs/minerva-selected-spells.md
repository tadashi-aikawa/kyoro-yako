# ミネルヴァの必殺技の現行仕様

## 採用済みの技

- サーベイは七重の輪の形を保ち、収縮後に輪の中心から放射状に広がりながら落下する。
  - 制約: 広い共通通路や弾の自動削除は設けない。
- グラビティ・シフトは自機狙いの扇、輪、星の雨を交代で放つ。
  - 重力: 8秒周期。予告後の3秒間、自機だけを右・下・左・上へ押す。上向きの力は他方向の65%。
  - 操作: 低速でも反対入力で抗える。ポーズと技終了で流れも止まる。

## リトラクション

- 意図的な穴を設けず、全周へ等間隔で放出する。
  - 弾数: Easy40・Normal40・Hard56・Lunatic72。Easyにも端を通る弾数を確保し、遅い弾速と長い予告・発射間隔で難易度を下げる。
- 36〜60フレームの射線予告の後、毎フレーム4.5〜6.3pxで画面外48pxまで放出する。
- 画面外で42〜60フレーム停止し、毎フレーム3.2〜4.4pxで移動中のミネルヴァへ戻る。
- 本体は横幅200px・周期510フレームの楕円軌道で動く。停止中から帰還先を毎フレーム更新し、帰還中も本体へ向きを変える。自機は追わない。
- 魔法陣は本体に重ねる。場外の停止中には帰還線を出さない。帰還弾が画面へ入る約3フレーム前から、現在の帰還先への線と端の矢印を表示する。帰還速度は維持する。
- 通常の画面外削除から除外し、帰還後か寿命上限で消す。ボム・技終了でも消す。
- 場外にいる弾を撃破で得点へ変える場合、アイテムは画面内の縁へ寄せる。

## オウル・オブ・ミネルヴァ

- 過去ボスの9技を候補にする。
  - 除外: 「ノーマルモードから逃がさない」は最終技では使わない。ネオ戦本編は維持する。
  - 抽選: 未登場・登場済み・直前の技の重みを10000:100:1にする。
  - 連続: 祈りは登場履歴へ追加せず、祈りを挟んでも直前の再演を選びにくくする。
  - 履歴: 重複を含む選出順を記録し、最終技の開始・ステージやり直しでリセットする。
  - タイミング: HPの切替条件を満たすまでは再抽選せず、ボム単独でも再抽選しない。
- 借りた技3回→祈り→借りた技4回→祈り→借りた技3回→最後の祈りの順で進む。
  - 枠数: 技10枠と祈り3枠。
  - HP配分: 最初の12枠は最大HPの7.5%ずつ、最後の祈りは10%とする。
  - 切替: 開始時のHP差分ではなく、最大HPからの固定境界を使う。
    - 理由: 超過ダメージが積み重なって最後の祈りを短くしない。
  - 最後: 3回目の祈りは撃破まで保つ。時間による自動切替はしない。
- 最終技の被ダメージは通常の2/3とする。HP3888は維持し、実効耐久は通常の5832相当。
- 再演の前に60フレームの召喚を入れる。ミネルヴァが袋を開き、光粒と魔法陣から元キャラの霊が現れて射撃を始める。召喚中は無敵とし、攻撃前のスキップを防ぐ。
- 借りる技と祈りの難易度はそれぞれ決める。
  - 第1区間: 技3回と1回目の祈りは選択難易度。
  - 第2区間: 技4回は1段階上。中盤の祈りは選択難易度の2種。
  - 第3区間: 技3回は2段階上。最後の祈りは1段階上の2種。Lunaticを上限にする。
  - 固定: 難易度は各技と各祈りの開始時に決め、その途中では変えない。
  - 元設定: プレイヤーが選択した難易度は変更しない。
- 第3区間で、本体の周囲に金白色の炎状のオーラを表示する。
  - 切替: 2回目の祈りのHP区間が終わると危険物を全消去し、60フレーム静止する。
  - セリフ: 吹き出し中央に「……」だけを264フレーム表示し、無言で間を置く。
  - 補給: セリフ後、パワー最大なら光の羽根1個、未到達なら最大までに必要な数の大型パワーの羽根を出す。ボムと残機アップも各1個出し、短く広がってから自動回収する。このセットの受け取りを待つ。
    - 最大到達前: 不足分を切り上げた個数の大型パワーの羽根を出し、パワーは5で止める。光の羽根は追加しない。
    - 最高形態中: 光の羽根は既存のスコア変換を使う。
  - 開始: 補給を受け取った後の60フレームでオーラを立ち上げる。さらに60フレームの間を置いてから攻撃し、最後の祈りまでオーラを保つ。
    - 召喚: 霊・技名・次技への移動はオーラが完成してから始め、最後の60フレームの間に従来の召喚を重ねる。
  - 保護: 切替中は本体へのダメージと接触被弾を無効にし、次のHP区間へ進めない。プレイヤーの移動とアイテム回収は続け、射撃とボム入力は攻撃開始まで止める。
    - 例外: 突入前の被弾に対する喰らいボムは受け付ける。
  - 表現: 淡い紫の縁と上昇する光を使い、独立した弾状の粒は置かない。
  - 描画: 本体と弾の背面に置き、分身時は本体の位置・不透明度に同期する。
  - 時計: ポーズ中は止め、ボム中は動かす。
  - 終了: HP0・フェーズ導入中・他の技・リトライ後には出さない。
- 再演は既存の技の弾・予告・移動・反射・風・グラフを再利用する。
  - 花影: ミネルヴァ自身が分身し、溜めと分身中は祈り画像を使う。全員が共有HPへの命中対象となり、再演時は単身で5秒撃つ前置きを省き、召喚直後から祈って分身する。分身後の射撃・跳躍は元技を使う。
  - 本体: ミネルヴァを維持する。元のボスのHP・制限時間・キャラへ切り替えない。
  - 面影: 構えから再演終了まで、本体の横34px・下12pxへ高さ112pxの半透明スプライトを浮かべる。中心のY座標は最低154pxとし、顔を技名の帯より下に収める。本体と重なりつつ背面へ描く。召喚開始30フレーム後から24フレームかけて現れ、濃さは0.54〜0.62。技ごとに左右を固定し、移動の途中で反対側へ飛ばない。弾より後ろへ描き、祈り中は出さない。
  - 表示: 借りる技の名前は召喚カットインで読ませる。
    - 召喚カットイン: 元キャラの顔・名前・技名を小さな横長のカットインで1.4秒表示する。
    - 文言: 技名には「再演」などの接頭辞を付けない。
    - 描画順: 弾と予告をカットインより手前に描く。
- 再演と祈りの切替時には、弾・レーザー・グラフ・後続射撃の状態を全て消す。
- 祈りは溜め72フレーム、発散180フレーム、休止108フレームを維持し、HP条件を満たすまで360フレーム周期で繰り返す。
  - 位置: 溜めの最初60フレームで中央の座標192・132へ戻り、固定して発散する。
  - 弾種: 1回目は主渦だけ。中盤と最後は主渦と逆回転の星弾を使う。
    - 逆渦: 発散開始72フレーム後から、主渦の半分の頻度・やや低い速度で追加する。
  - 補給: 祈りの最初の発散時に、下向きの弾1発を残機・大型パワー・ボム各1個へ替えて放つ。配布時のPowerが5なら25%で光の羽根も追加する。同じ祈りのHP区間では1セットだけとし、6秒周期で繰り返しても再配布しない。ボム中も配布する。弾と同じ半径22pxの発射点から0.45rad間隔の下向きの扇で放ち、初速は1.5px/fとする。既存の落下・近距離吸引・収集処理とアイコンを使い、上部での自動回収はしない。
- 時間表示∞、HP3888、撃破必須とする。クロディーヌの最終技には影響させない。
- ボム中も全体時計と風向きの更新を続け、弾と危険物は消す。未実行の斉射をまとめて復活させない。
- 星図は使わない。

## 削除した技

ソクラティック・メソッドは、タダシの指示で削除した。直前の通常攻撃「観測の螺旋」も外し、通常攻撃が連続しない構成にした。新しい代替技は追加しない。
