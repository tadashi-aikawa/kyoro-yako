# ミネルヴァの必殺技の現行仕様

## 採用済みの技

- サーベイは七重の輪の形を保ち、収縮後に輪の中心から放射状に広がりながら落下する。
  - 制約: 広い共通通路や弾の自動削除は設けない。
- グラビティ・シフトは自機狙いの扇、輪、星の雨を交代で放つ。
  - 重力: 8秒周期。予告後の3秒間、自機だけを右・下・左・上へ押す。上向きの力は他方向の65%。
  - 操作: 低速でも反対入力で抗える。ポーズと技終了で流れも止まる。

## リトラクション

- 意図的な穴を設けず、全周へ等間隔で放出する。
- 36〜60フレームの射線予告の後、毎フレーム4.5〜6.3pxで画面外48pxまで放出する。
- 画面外で42〜60フレーム停止し、毎フレーム3.2〜4.4pxで発射時の原点へ戻る。
- 原点は発射時に固定する。予告中に本体が移動しても、魔法陣を原点へ残す。
- 停止中は原点への線を描く。画面外から戻っている間も、端の矢印で進入方向を示す。
- 通常の画面外削除から除外し、帰還後か寿命上限で消す。ボム・技終了でも消す。
- 場外にいる弾を撃破で得点へ変える場合、アイテムは画面内の縁へ寄せる。

## オウル・オブ・ミネルヴァ

- 過去ボスの12技から、周期ごとに1技を等確率で独立に抽選する。
  - 条件: 同じ技の連続も許す。プレイごとに変わり、HPやボムによる再抽選はしない。
- 流れは構え60フレーム、再演600フレーム、祈り360フレームの17秒周期とする。
- 再演は既存の技の弾・予告・移動・反射・風・グラフを再利用する。
  - 本体: ミネルヴァを維持する。元のボスのHP・制限時間・キャラへ切り替えない。
  - 面影: 構えに元キャラの半透明スプライトを背後へ重ねる。18フレームで最大0.28、60フレームで0.12、105フレームで消える。
  - 表示: ボス名と残り時間の間に、再演中の技名を添える。最終技名とボーナスの枠は広げない。
- 再演と祈りの切替時には、弾・レーザー・グラフ・後続射撃の状態を全て消す。
- 祈りは溜め72フレーム、発散180フレーム、休止108フレームを維持する。
  - 位置: 溜めの最初60フレームで中央の座標192・132へ戻り、固定して発散する。
- 時間表示∞、HP3888、撃破必須とする。クロディーヌの耐久には影響させない。
- ボム中も全体時計と風向きの更新を続け、弾と危険物は消す。未実行の斉射をまとめて復活させない。
- 星図とHPによる3段階は撤回する。

| 元ボス | 再演する技 |
|---|---|
| ネオ | ノーマルモードから逃がさない、リターン・トゥ・センダー |
| オブシディア | 断捨離、グラフビューの天網、インボックス・ゼロ |
| クロディーヌ | タイポグラフィの雨、グリッドシステム、補色の対比、余白は語る |
| 迅雷 | 宵の誘い、夜桜の簪、夜桜の舞 |

## ソクラティック・メソッドの再設計

現行の「推論の門」は差し戻し中。2段変換の読解負荷と、ボス前に居続けられる安置を撤回する。

- 候補A: 「すべての扉に☆がある？」に対し、☆のない反例の扉を探す。
- 候補B: 3つの記号列から、ほかの2つと違う並びを探す。
- 共通案: 1回の観察で判断できる問いにする。不正解の列はボス前まで含む全高へ予告弾を出し、固定位置で問題を無視する抜け道をなくす。
- 状態: 質問票で方向性を確認するまで、新しい仕掛けは実装しない。
