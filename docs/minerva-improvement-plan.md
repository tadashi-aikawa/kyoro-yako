# ミネルヴァの必殺技の改善

採用後の仕様は[spell-design.md](spell-design.md)と[minerva-selected-spells.md](minerva-selected-spells.md)を正本とする。

## 先行実装からの再調整

- セブンフォールド・サーベイの広い共通通路は撤回した。
  - 理由: 安全地帯が広すぎ、七重の輪としての魅力が失われたとの実機フィードバックを受けた。
  - 変更: 七重の輪と小さな切れ目を残し、収縮後は円形を保って拡大しながら落とす。
- リトラクションの意図的な穴は撤回した。
  - 変更: 全周へ等間隔で放出し、縁で一拍停止して同じ原点へ戻す。
- パノプティコンの端の揺れ、フライトとインクワイアリーのHP連動は維持した。

## 質問票の回答

- ソクラティック・メソッドはA「推論の門」を採用した。
  - 不採用: B「反例探し」。
- トゥルース・オア・デコイは廃止し、備考の別案を「グラビティ・シフト」として実装した。
  - 採用: 通常攻撃のように複数の弾幕を放ち、一定時間ごとに重力で自機を一定方向へ流す。
  - 不採用: A「コンジャンクション」、B「プリズマティック・リフラクション」。
- オウル・オブ・ミネルヴァはA「夜明けの星図」を採用した。
  - 共通条件: 祈りの発散は残す。時間表示∞、撃破しないとクリアできない。
  - 不採用: B「星雲の潮汐」。
