# ミネルヴァの必殺技の改善

## 今回実装する5技

- セブンフォールド・サーベイ
  - 七重の輪と収縮は残す。落下時に左右へ広がり、端にも弾を届ける。
  - 全層に共通の縦の隙間を開ける。隙間の幅はEasy 72px、Normal 64px、Hard 56px、Lunatic 48pxを下限とする。
  - 隙間を生成前から予告する。生成時に隙間内の弾を省き、収縮中も隙間へ入る弾を取り除く。落下後は弾を隙間の外へ流す。
  - 波の間隔を広げ、違う隙間を同時に要求しない。次の隙間は前の位置から通常移動で移れる範囲にする。
  - Easyは最初のスペルとして中央に狭い待機可能範囲を許す。連続した幅は予告通路の半分以下に制限し、両端の安置は全難易度で解消する。
- パノプティコン
  - 端の列も左右に動かす。弾の中心を自機の可動域の端まで届ける。
  - 視線による停止と既存の列数・速度は保つ。
- リトラクション
  - 弾を画面下半分と左右の縁まで放射する。
  - 画面内で一拍停止し、予告後に発射時の原点へ引き戻す。戻り終わりに消える。
  - 原点は発射時に固定し、移動中のボスや自機には追従しない。途中で瞬間移動しない。
  - 往復で弾が密集しすぎないよう、下向きに抜ける隙間と波の間隔を確保する。
- アストラル・フライト
  - 2羽はHP75%以下または15秒、3羽はHP35%以下または40秒で始める。
  - 切替時刻を保持し、HPが戻っても段階を戻さない。飛行中の羽と軌跡は消さない。
  - 3羽目は2羽への切替から最低2秒空ける。ボム中は新たに発射しない。
- エンドレス・インクワイアリー
  - HP40%以下または30秒経過後に放出間隔を半分にする。
  - 既存の時間条件だけで進む場合の発射時刻・色順・交互回転を保つ。
  - HPでの切替も直前の発射から半周期以上を空ける。発射済みの輪は変更しない。
  - ボムで段階を巻き戻さず、技を最初から始めると初期段階へ戻す。

## 実装前に選ぶ3技

以下は未採用の候補。質問票の回答後に具体化する。

### ソクラティック・メソッド

- A 推論の門。推奨。
  - 例: 上部に「◇→○」「○→☆」が出る。「◇を2回変換すると？」の問いが来たら、答えの☆の門へ向かう。
  - 流れ: 二つの手がかりを提示 → 問いと3つの門を予告 → 答えの門に隙間が開き、他の門から弾列が落ちる。
  - 考えること: 記号の対応を2段つなげて、避ける場所を先に決める。
  - 読みやすさ: 同じ画面内に手がかりを残す。色だけで区別しない。答え確定後に十分な移動時間を置く。
  - 救済: 間違い側も即死の壁にはせず、密だが抜けられる弾列にする。正解なら広く、間違えても腕で立て直せる。
  - 抜け道への対処: Normal以上は、正解が開くのを見てから遠い門へは間に合わない予告にする。Easyでは見てからの回避も許す。
- B 反例探し。
  - 例: 3列の「○△○△」「○△△△」「○△○△」から、規則が崩れた中央を見つける。
  - 流れ: 3列の記号列を提示 → 違う列を見抜く → その列が安全な通路になり、残りが弾列になる。
  - 考えること: 手がかりを組み合わせるより、繰り返しの中の違いを観察する。
  - 読みやすさ: 1回に使う規則は1種類。記号を小さく詰め込まず、答えが一意になる配置にする。
  - 救済: Aと同じく、間違い側にも弾の隙間を残す。

### トゥルース・オア・デコイを廃止して入れる新技

- A コンジャンクション。推奨。
  - 例: 速度の違う3つの星が公転し、2つの星とボスが一直線に並ぶ。その直線に沿って星の弾列が走る。
  - 流れ: 公転を見る → 並びかけた星と射線が光る → 星の会合で弾列が走る。
  - 遊び: 星の動きから、次に危険になる射線を予測して避ける。天文台の観測を弾幕にする。
  - 制約: 公転する星そのものは無害。射線を先に固定してから発射する。エトワールの輪と異なり、星は軌道から外れず、接線方向にも撃たない。
- B プリズマティック・リフラクション。
  - 例: ミネルヴァの光弾が三角のプリズムに入り、向きを変えて自機のいる下半分へ抜けてくる。
  - 流れ: プリズムが向きを定める → 折れ曲がる射線を点線で予告 → 光弾がその道を通る。
  - 遊び: Aの「星が並ぶ時刻」ではなく、屈折して届く進路を読む。
  - 制約: プリズムは無害。照準の確定後は回転しない。1回に1つのプリズムだけが働き、見えない反射や無予告の枝分かれを作らない。

### オウル・オブ・ミネルヴァ

共通方針:

- 祈って溜め、渦を発散する攻撃を残す。他の横断編隊・ランダムに飛ぶ接触フクロウ・後方弾は置き換える。
- 残り時間の表示は∞。時間切れでは終わらず、HPを削り切って初めてクリアする。
- HPに応じて3段階に変化する。時間経過だけで際限なく強化しない。
- 撃ち込みの目安は約60秒。回避で伸びても時間切れにはしない。祈り中もダメージを与えられる。
- A 夜明けの星図。推奨。
  - 例: 梟の翼をかたどる7つの星が現れる。翼の一部が順に光り、その向きへ羽の弾列が放たれる。
  - 流れ: 星座の出現 → 星の点滅で順番と方向を予告 → 翼に沿った弾列を順に放つ → 祈りの渦 → 星座を組み直す。
  - 遊び: 次に放つ翼を読み、小さく避けながら撃ち込む。HPが減ると翼の向きと発射順が変わる。
  - 制約: 星を結ぶ線は描かず、点滅と短い矢印で予告する。星座を無制限に増やさない。祈りの渦とは交互に出す。
- B 星雲の潮汐。
  - 例: 背景の星雲が右へ流れ、自機と弾がゆっくり右へ押される。流れを見て位置を調整し、弾の間を抜ける。
  - 流れ: 星雲と矢印で次の流れを予告 → 上下左右のどれかへ潮が動く → 流れが緩んで祈りの渦 → 次の潮へ。
  - 遊び: Aの「発射順を読む」より、流れを使って撃ち込む位置を取り直す操作が中心になる。
  - 制約: 自機を押す量は低速移動より十分小さくする。祈り中は潮を止める。入力を無効にする強制移動や、画面端への押し込みは作らない。
