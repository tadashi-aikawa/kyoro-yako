# ミネルヴァの必殺技の改善

採用後の仕様は[spell-design.md](spell-design.md)と[minerva-selected-spells.md](minerva-selected-spells.md)を正本とする。

## 先行実装からの再調整

- セブンフォールド・サーベイの広い共通通路は撤回した。
  - 理由: 安全地帯が広すぎ、七重の輪としての魅力が失われたとの実機フィードバックを受けた。
  - 変更: 七重の輪と小さな切れ目を残し、収縮後は円形を保って拡大しながら落とす。
- リトラクションの意図的な穴は撤回した。
  - 変更: 全周へ等間隔で放出し、縁で一拍停止して同じ原点へ戻す。
- パノプティコンの端の揺れ、フライトとインクワイアリーのHP連動は維持した。

## 質問票の回答

- ソクラティック・メソッドはA「推論の門」を採用した。
  - 不採用: B「反例探し」。
- トゥルース・オア・デコイは廃止し、備考の別案を「グラビティ・シフト」として実装した。
  - 採用: 通常攻撃のように複数の弾幕を放ち、一定時間ごとに重力で自機を一定方向へ流す。
  - 不採用: A「コンジャンクション」、B「プリズマティック・リフラクション」。
- オウル・オブ・ミネルヴァはA「夜明けの星図」を一度採用し、試遊後に撤回した。
  - 共通条件: 祈りの発散は残す。時間表示∞、撃破しないとクリアできない。
  - 不採用: B「星雲の潮汐」。

## 試遊後の変更

- サーベイとグラビティ・シフトは採用して維持する。
- リトラクションは高速で画面外まで放出し、一拍停止後に移動中の本体へ戻す。帰還先は発射地点に固定しない。
- 最終技は「ノーマルモードから逃がさない」を除いた1〜4面の9技から抽選する。
  - 重み: 未登場・登場済み・直前の技を10000:100:1にする。
  - 進行: 1秒の召喚後に技を借り、3回・4回・3回の技の後に祈りを挟む。
  - HP: 被ダメージ2/3、最初の12枠は最大HPの7.5%ずつ、最後の祈りに10%を割り当てる。
  - 面影: 再演中ずっと背面へ重ねる。
- 再演と祈りの開始時に段階強化する。
  - 第1区間: 選択難易度のまま。
  - 第2区間: 1段階上。
  - 第3区間: 2段階上。Lunaticを上限とし、本体に金白色のオーラも出す。
    - 切替: 危険物消去後に無言で0.5秒静止し、オーラを1秒見せてから1秒の召喚へ進む。切替中は本体へのダメージと接触被弾を無効にする。
  - 固定: 進行中の技は同じ難易度を保つ。
- 祈りで補給を配る。
  - 弾種: 最後の祈りだけ逆回転の星弾も混ぜる。
  - 補給: 最初の発散へ残機・大型パワー・ボム各1個を混ぜる。Power5なら25%で光の羽根も追加する。
- ソクラティックと直前の通常攻撃は削除する。代替技は追加しない。
