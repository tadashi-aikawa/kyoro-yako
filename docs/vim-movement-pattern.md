# ネオのHJKL専用移動

「ノーマルモードから逃がさない」の間は、矢印キーを無効にしてHJKLだけで移動する。

| キー | 移動 |
|---|---|
| H | ← 左 |
| J | ↓ 下 |
| K | ↑ 上 |
| L | → 右 |

- 技の開始から終了まで制限する。
    - 解除: 撃破・時間切れ・スキップで次の技のアイテム回収へ入った時点。
    - 維持: ボム・被弾では解除しない。
- Shiftの低速移動・斜め移動の速度補正・Zのショット・Xのボム・Escのポーズは通常どおり。
- HUD下部の記録欄を、キーと方向の対応表へ切り替える。
    - 表示: 技の間は常設し、押したキーを明るくする。
- 自機の周辺にも、上にK↑・下にJ↓・左にH←・右にL→を常設する。
    - 表示: 自機に追従し、画面端では外周の余白まで使って方向の位置関係を保つ。無敵の点滅やボム中も消さない。
- 開始演出後も、Easyから順に150・150・120・105フレームは弾を出さない。
    - 表示: この間は中央にもキー対応と矢印キーが使えないことを表示する。
- 弾幕は左右に抜け道がずれる横列と、疎らな自機狙いの扇弾。
    - 横列: 間隔126・114・102・90フレーム。抜け道の幅112・100・88・78px。
    - 出現: 画面外の上から降らせる。列のX座標は波ごとに半マスずらし、固定の安全列を残さない。
    - 扇弾: 横列2波ごとの合間に3・3・5・5発。
    - 描画: 通常弾だけを使い、Vimコマンドの予告・コピー・消去は行わない。
- ボム中は弾を出さない。終了後は次の射撃タイミングから再開する。
- ポーズ中は移動と弾幕の時計を止める。

Chromeでは実キーによる4方向移動、矢印無効、Shift、ショット・ボム・ポーズ、終了後の復帰、4難易度の回避と撃破を確かめる。
